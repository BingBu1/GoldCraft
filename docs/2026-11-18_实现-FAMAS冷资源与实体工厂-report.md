# FAMAS 冷资源与实体工厂

FAMAS 的真实 SDK 实体工厂与冷资源准备已经实现并通过独立回归。整枪的实际 Host、玩家后端、客户端效果、作者 P 模型、HUD 和购买菜单仍需连接；此阶段不把 FAMAS 开放购买，也不宣称为第十把已交付武器。

原版样本为 CoF MP，PE32/x86，基址 `0x10000000`，SHA-256 `0036b91c01e92ed205513f52563053a55a66a32d257efb5f476b8f1f3dde0e63`。修改前证据 `PREEDIT-cold-factory.json` 位于私有目录 `analysis/cof-weapons-20261111/famas-20261118/`。本次接续重新核对完整样本、八个区域、六份 IDA 归档和实际测试输入；亦从现有自有会话读取三个原函数窗口。原始字节和游戏资源不随源码发布。

机械闭包为有效 V/W 和明确匹配的库存身份。机瞄参数、序列时长、作者 P、可选模型与声音分别保存准备状态；可选项失败不会撤销已经有效的机械资源，原有严格准备 API 仍保留。所有输出以当前地图代次原子提交，准备途中失效不提交半成品。

原资源树没有 P 模型。第三人称模型必须随后制作和校准，不能用猜测的 P 或动作替代。原 loose 树也没有 `w_9mmclip.mdl`，这项依原引擎继承 VFS 规则解析已有受核对资源；不伪造同名文件。

- `build/cof-magazine-model-20261118-04`：4,138 组原版时长对照、4,142 组部分准备对照、124 条实际模型序列和 57 项边界检查通过。

运行时准备仅在冷阶段进行，输出不持有加载文件指针；不在绘制、射击或逐实体循环中加载资源。上述是独立 SDK/资源验证，尚不包括 Host 安装、P 作者资产、真实客户端、网络多人和实际性能。
