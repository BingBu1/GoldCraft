# M玩家首页与管理员持久设置

本阶段将已加入灾变玩家的 M 扩展为共同首页，管理员通过其中“服务器管理”进入原功能和新增持久设置。初次选人、非灾变及断线状态继续原 `chooseteam`。盲盒消费和熟练度统计仍明确显示服务尚未就绪，不造扣款、发奖或进度；没有运行服部署和真人菜单验收。

## 源码与权限

修改范围为 [goldcraft_scenario_admin.sma](../amxx/scenario/goldcraft_scenario_admin.sma) 和 [公共声明](../amxx/scenario/include/csol_scenario_admin.inc)。管理员页保留原八项及其顺序：通关留图、换图、重玩、目标地图命令、难度、立即重玩、通关投票、立即投票；新增第九项持久玩法设置。专服原管理命令保留。

共同首页不显示普通玩家的管理入口；权限失效时，即使菜单仍在屏幕上，提交仍重新校验。菜单拥有者、userid 和配置 revision 分别记录；文本输入另外记录 setting index、key 和类型。M/菜单切换、断线和插件卸载撤销旧输入。所有新菜单选择、数值提交和异步结果均重新核对 Scenario、JOINED、当前连接 userid 与 `ADMIN_CFG`。原难度和通关管理也补上菜单 userid 核对。

设置页从真实 typed native 目录读取，不拼任意 CVAR 或服务器命令。布尔点击翻转，数值进入固定 `messagemode csol_custom_value`。输入只接受非负整数或普通小数，拒绝指数、NaN/Inf、分隔符、多个词、溢出、越界和过时 revision/key。当前 native ABI 使用 Pawn Float，不能准确表示的整数明确拒绝，避免悄悄舍入用户输入。

Edit 返回 Queued 时仅报告排队。最多 80 次、间隔 0.25 秒查询状态；只有结果 Saved、revision 恰好增加 1、对应值核同、当前管理员身份仍一致时，才报告“已永久保存到 JSON”。失败保持未确认；等待超时只说明后台仍在处理，不能称保存失败或成功。即使接口直接返回 Saved，也先复核 revision/值。保存配置不代表对应玩法消费者已经完成。
