# 修复：新增近战武器在购买菜单中不显示

用户报告（2026-11-04）：新加的近战武器在购买菜单里不显示。本报告由 Claude 领域会话完成，交主协调（GPT）核收部署与实机。

## 原因

青龙偃月刀（桥接 ID 1022）与旋风 SKULL-9（1023）的实体、发放事务和服务端 `WeaponService::Deliver` 近战分支都已接好，但共享购买目录 `native/csol/buy_menu.cpp` 从未加入这两项，所以客户端“近身武器”分类（category 9）是空的。此前不加的原因见[青龙/旋风报告](2026-11-02_还原-青龙偃月刀与旋风-report.md)：原版刀走仓库选装，HW 40 字节刀选装记录（`380D48C8`/`380D49B8`）不是 0x30 字节购买价格记录，原版购买价格无闭合证据。

## 决定

人类在 2026-11-04 明确选择：两把刀在购买菜单中**免费 $0**；若日后找到原版购买价格再改。此价格是人类决定，不是原版证据。

## 部署注意

**DLL 与资源必须同批部署**：新 DLL 只认 `models/csol/buymenu_v8.json`，若只部署 DLL 不部署 v8 JSON 及 `w1022.tga`/`w1023.tga`，服务端 `CSOL_PrecacheBuyMenu` 会失败、整个购买菜单不可用。v8 资源须进入服务器 cstrike 与 HTTP 下载。

## 实机验收要点

单B进入灾变：按 B → 第9项“近身武器”应列出两把刀并显示原版购买图与“价格：$0”；购买后切到对应刀；已持有同种刀时该项灰显；R 重购能重购刀而不影响两把枪的槽位。
