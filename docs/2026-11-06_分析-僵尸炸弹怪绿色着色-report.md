# 分析：扔僵尸炸弹的僵尸原版为绿色，当前为原色（未修复）

> 历史调查，相关结论已撤回：遗漏了 client → SharedDataMgr → HW 的间接调制链，部分字段基址也标错。以 [后续更正报告](2026-11-06_更正-技能6绿色原版颜色消费链-report.md) 为准；保留以下原文追溯，不作为实现依据。

用户 2026-11-06 报告：扔僵尸炸弹（普通技能 6）的僵尸在原版是绿色，现在是原色。

## 已确认

- 颜色来源是怪物表：用生产解析器读全部 `maps/ZBS_ZT_*.cso`（`build/csol-balrog-trail-20261105/render-inventory/rows-color.jsonl`），技能 6 的类型颜色列为 `80,228,91`（131 行），渲染列 column21 为 `0,0,0`（`kRenderNormal`、无 renderfx、amt 0）。以失落之城为例：24–27 `zombi_host`、29–32 `speed_zombi_host`、33–36 `heavy_zombi_host` 均为 `80,228,91`。其他颜色如 `128,128,64`、`228,112,0`、`72,62,130` 也出现在非技能 6 的类型上。
- 服务器已按原工厂顺序写 `pev->rendercolor = type.color`、`rendermode/renderfx/renderamt = column21`（`native/csol/server/scenario_monster_factory.cpp` 668–671）。原 MP `AddToFullPack 1140B740` 把 pev `+1EC/+1F0/+1F4` 的浮点颜色截断后写入 entity_state `+5C/+5D/+5E`（`1140BE5C–1140BE7A`），另把 pev `+1D0..+1D5` 六个字节写到 state `+74..+79`（含义未查）。
- GoldSrc/ReHLDS 与 MetaHookSv Renderer 对 `kRenderNormal` 的工作室模型不使用 rendercolor，所以当前显示原色。原 CSO 必然在客户端或引擎的模型绘制中，对普通模式也用了这个颜色，但**具体在哪一步、按什么公式着色（乘贴图、乘光照、还是叠加）尚未找到**。
- 已排查：CSO client `2A3A4E0`、`2A3D6A0`、`2ACD100` 和 hw `378EA79B` 等读写实体 `+348..+34B`（CSO cl_entity curstate 颜色，= curstate `+2EC` + `0x5C`）的位置，都只是复制/视图模型亮度，不是怪物着色；hw `377C7A41`、`377C86D0`、`377CA08A` 的 `+B70` 属于别的结构。capstone 线性扫描不能可靠覆盖函数边界，需要 IDA 定位工作室渲染入口后继续。

## 2026-11-06 续查（capstone 原字节，未开 IDA 库）

- CSO 客户端实体布局（hw `3770F84F`、`377781A7` 交叉确认）：curstate 在 `+2D4`，rendermode `+328`、renderamt `+32C`、rendercolor `+330..332`、renderfx `+334`。
- hw 中读取 rendercolor 的路径只在 rendermode 1（`3770F86B`、`377781F5`、`377231F8`、`37AC1A25`）或 renderfx 22（`37ACC088`）、24（`3770F97D`、`3788B847`）、26（`3770FA2C`、`3788B926`）时使用颜色；rendermode 0 且 renderfx 0 为白色。client `2AC9580` 是临时 rendermode 4 的另一路径。
- 原 MP 出生 `11399E5A–11399EA9`：renderfx/renderamt 先清 0，rendercolor = 记录 `+20/+24/+28`，rendermode/renderfx/renderamt = 记录 `+64/+68/+6C`（与本工程工厂一致）。原 ZT 读表 `11390A60–11390A80` 用 `12278584` 向量、`11390EC9/11390ED6` 再写 0 初始化 `+64/+68`；失落之城原表只有 18 列（无第 21 列），所以原版这三项同样为 0。原 MP 中也没有把 renderfx 立即数写成 24/26 的 `mov [reg+174h]`。
- 因此“绿色”不来自上述 rendercolor 通路。仍待查：技能 6 怪是否在运行时改 renderfx（经变量写入，如 `11397E50`、`113E15F0` 一类 setter 的调用者）、或绿色来自模型皮肤/材质（例如 `zombi_host` 的贴图或 CSO 材质 JSON），需 IDA 交叉引用这两个 setter 并检查 skill6 相关调用。

## 结论

按 `docs/CSOL_IDA_POLICY.md`，在找到原版着色代码前不实现，不猜测公式。下一步：在 IDA 中定位 CSO client/hw 的工作室模型绘制（`StudioDrawModel`/`StudioRenderFinal` 与 engine studio 光照/颜色调用），找出读取 curstate 颜色并作用于普通模式模型的分支及公式。当前普通僵尸由 CSOLSupport 自绘（`scene.cpp` `DrawAsset`），找到公式后在该着色器里实现。
