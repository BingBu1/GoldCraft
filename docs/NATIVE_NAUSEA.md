# 普通 CS 玩家的反胃画面

未配对 Minecraft 客户端的原生 CS 玩家现在可从权威服务端取得反胃投影。它复用已有 Renderer 场景投影接口，不要求本地 Minecraft 或图集。此实现已编译并通过自动验证，尚未部署或完成真人验收。

独立可选能力 2097152、消息 97 保持协议 30。48 字节载荷包含 world/revision/slot/serial/spawn/life、上一 tick 与当前强度、相位和每 tick 角速度。仅服务端角色可协商；旧宿主拒绝时依次撤回可选能力。ReGameDLL 校验当前权威连接、玩家身份、生命及重入后的实体，可靠消息 GCNausea 只发给本人；中继使用独立递增序号，避免 MC 断线重连后旧序号阻挡恢复。

发布器读取唯一效果持有者，每个世界 tick 只推进一次。使用固定版本原版 `isDurationBelow(60)`：该方法包含等于，所以剩余 61 tick 时仍渐入，60 tick 开始每 tick 减少 0.05；正常渐入每 tick 增加 0.006666667，上限 1。普通移除、内部移除、全部清除和自然到期均归零，移除后立即重加不会继承旧强度。转移同一个效果实例的属性移除钩子不视为喝奶清除；新的 life、spawn、身份、世界或连接代次以及 ticker 中断重新建立状态。

客户端在收到后的一 tick 内插值，到达末值后保持至 350 ms 租约到期，禁止继续外推；死亡、观战、形态/身份变化或协议不匹配不能沿用旧状态。配对客户端的实际输出优先，包括辅助功能设置产生的零强度；已协商配对通道但帧过期时清零，不用全强度回退覆盖减少动态效果的设置。未配对回退使用完整投影，不另造缺少绿色覆盖层语义的辅助功能开关。传送门画面仍由配对客户端原版路径处理。

生产 GoldCraft、ReGameDLL 与 NeoForge JAR 构建成功。350 项 JUnit、111 项原生反胃检查、53 项既有视觉检查及 76 项配对投影检查通过。正式 JAR 在无附加 Mod、Epic/NightFall 两种真实 NeoForge 环境各通过 1,337 项检查，覆盖完整渐入、末段衰减、普通/内部移除与即时重加、无限效果、唯一效果持有者交接、tick/生命/身份/世界变化和真实 BridgeLink TCP。第一次测试误把 60 tick 视为继续渐入，真实运行纠正了这一预期；生产代码一直调用原版方法，失败记录保留。

证据：`build/native-nausea-20261018/checkpoint.json`。测试使用真实 MC 实体和效果钩子，宿主快照与客户端连接是夹具；不是双服联机、实机画面或固定视角 FPS 的证据。联合候选还保留枪镜、生命上限、发光等之前修复，待下一次统一部署后验证双形态、普通未配对客户端、多玩家、断线/重生/换图和长期帧时间。
