# 原生 CS 爆炸击退

2026-10-19普通近战缺口复核：`NativePlayerHitboxEntity.takeKnockback`仍为空；逻辑玩家的代理速度还会在tick/update清零。后续实现须覆盖实际受击和攻击者追加击退，保留NeoForge取消/抗性，并与`NativeHitEffects`的宿主伤害确认衔接。现有Actor含权威速度，但flags仅含存活/蹲伏/观战/Bot/配对/控制/形态；NativeView也只有水体标记，没有落地状态。应先扩展可协商的权威移动状态，再计算原版击退；不能把代理默认落地或零速度作为真实CS运动，也不能直接在异步伤害拒绝前推玩家。本次仅确认缺口，未修改或部署近战击退。

2026-10-18：蓄风和普通 MC 爆炸的最终击退已接入 ReHLDS 原生玩家移动。生产 Core/mp 候选构建、371 项 JUnit、真实 NeoForge 两环境各 26 项、真实双服 9 项通过；受伤双服 14 项和死亡效果 38 项回归通过。本次候选尚未部署，图形、多人和完整玩法仍待联合验收。

## 原因与行为

固定 Minecraft 1.21.1 / NeoForge 21.1.256 的爆炸路径在曝光量、抗击退属性和 `ExplosionKnockbackEvent` 处理后，直接调用 `Entity.setVelocity`。原生玩家的 MC hitbox 只用于代理碰撞与效果，改它的速度不能驱动 CS 玩家；`takeKnockback` 也不是爆炸的入口。旧 Core 的实际蓄风对照已经算出非零向量，但没有发出原生位移消息。

`HostExplosionMixin` 在这一次原版速度写入处提取增量，保留原来的 MC 写入，再交给独立的 `NativeImpulse`。因此蓄风不造成伤害也能推动玩家，普通 MC 实体继续走原版行为。Mod 修改为零、取消爆炸、移出爆炸目标列表，以及原版爆炸抗击退属性均保留。

## 权威与兼容

新增可选能力 `33554432` 和消息 `101`，协议版本仍为 30。只允许已认证的 MC 专服向 ReHLDS 专服发送；图形客户端不具备该能力。老宿主拒绝新能力时按既有能力链降级，不更换身份凭据。

消息固定 64 字节：world/event/snapshotTick 三个 uint64；slot/serial/spawn/life 四个 uint32；权威快照身体中心和速度增量六个 float32。MC blocks/tick 转换为 GoldSrc units/second：`(x*640, -z*640, y*640)`。

MC 端核对当前世界、维度、连接、身体、出生、生命、阵营和原生形态。ReHLDS 再核对当前身份/生命、存活、非观战、原生步行、事件去重和已实际导出的身体快照：快照不超过一秒，提交中心须匹配记录，当前中心移动不得超过 64 单位。NaN、无穷、越界和错误包长均拒绝。连接或世界更新会重置事件序列，旧生命不能领取冲量。

有效冲量累加到真实 `pev.velocity`，正向上冲量清除 `FL_ONGROUND`；之后由原生引擎处理移动、碰撞、摩擦、重力和最大速度。不会改变坐标所有权或强制切换形态。

## 验证与边界

- 362 个 Java 输入在冻结副本与当前源码之间一致，生产构建和 371 项 JUnit 通过。745 个原生输入在最终构建后记录，均早于 DLL，随后哈希无变化；原生消费者 98、协议 1068、共享伤害快照 31 项通过。原生消费者测试使用实际处理函数及明确的引擎适配器。
- `tools/Test-NativeImpulse.py` 在真实 NeoForge 中运行原版风爆和普通爆炸。无附加 Mod、Epic Fight/NightFall 环境各 26 项，覆盖最终事件向量、零冲量、取消、目标裁剪、抗性、旧生命、断链及普通 MC 实体。宿主快照和接收端在这组测试中由夹具提供。
- `tools/Exercise-NativeImpulseServers.py` 连接真实 ReHLDS 和 NeoForge，仅观察未经修改的 actor/impulse 消息。两个附近原生玩家各收一次冲量；目标玩家真实速度变化并由引擎移动，生命保持 1000。一次样本从 `(524,176,36.03125)` 移动到 `(512.03125,176,116.90397)`，保留地图碰撞。Mod 零冲量与取消均无目标位移消息。假玩家由 AMXX 1.10 的实际 `RunPlayerMove` 驱动空输入帧，不直接改写验证阶段的位置。
- 既有真实双服受伤/取消/吸收/飘字单次加载 14 项及真实 NeoForge 死亡效果 38 项回归通过。所有测试服均正常停止，原生夹具恢复。生产 Pawn 未改，本次新增的移动驱动只在隔离测试插件内。

证据目录：`build/native-impulse-20261018`；最终双服为 `servers03`。保留的前两次失败分别是把两名受力者误计成单人重复，以及测试假玩家未发送移动帧。旧版 `baseline02` 是有效行为负对照；`baseline01` 在握手前失败，不能作为玩法对照。

37 项 `combined-native-impulse-20261018` 候选仅替换 Core 和 mp，继承已部署批次的 AMXX 1.10、飘字及客户端修复，尚未整体部署。本次真实双服由 MC 僵尸死亡触发风爆；原生死亡触发路径另有 38 项回归，尚无原生死亡源到原生受力者的完整真人链路。普通近战推力、完整原版水中 travel、真实客户端预测和多人体验仍须继续验证，不能据此关闭全部状态效果或完整目标。
