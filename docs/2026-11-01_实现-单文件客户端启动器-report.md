# 单文件客户端启动器

2026-11-01。范围为人类本轮要求的七项启动器功能，以及与既有 HTTP 共端口的发布接口；总 goal 保持暂停，未恢复其他协调任务。唯一跨对话协作为人类指定的 CSOL 核心对话，并仅涉及此启动器的引擎接线、CPU 窗口和源码发布。

## 已实现与交付

`dist/GoldCraftLauncher/GoldCraftLauncher.exe` 为 Windows 10/11 x64 单文件程序，75,012,469 字节，SHA-256：

```text

```

内置 .NET 运行时及 374 个 MetaHook 安装文件，安装资源压缩后 23,231,075 字节。自动读取 Steam 库与 CS 清单；首次安装、目录修复、状态刷新、启动前核心更新使用中文窗体。完整安装校验通过才可启动，安装和更新都拒绝修改正在运行的该目录游戏。

网上更新仅限内置白名单的 19 个插件/支持库 DLL。元数据由内置公钥验证 RSA-3072/SHA-256 签名，文件校验长度与 SHA-256，拒绝回退版本、错误资源合同和白名单外路径。只下载发生变化的 DLL。安装与更新为有日志的文件事务，支持中断恢复、失败回滚及两份备份；替换硬链接目标时使用独立临时文件。

## HTTP 接口和配套状态

新路由复用原 ReHLDS HTTP 监听器：

```text
/goldcraft/launcher/v1/status.json
/goldcraft/launcher/v1/manifest.json
/goldcraft/launcher/v1/blobs/<sha256>/<basename>.dll
```

引擎主线程每秒制作状态快照，工作线程读取快照或固定发布目录文件，不直接访问游戏状态。保留普通资源白名单和 `/spray/` 转发；没有新增公网端口。默认发布目录为服务进程工作目录下 `launcher-public`，与 `cstrike` 同级。

已生成 `build/client-launcher-20261101/release-02/launcher-public`，版本序号 2026110101，包含签名清单及 19 个按哈希命名的 DLL。私钥留在本机受 Git 排除的工具目录，不包含在 EXE、公开目录或服务端交付内容中。

截至本报告检查点，新的生产引擎正在指定对话合批准备，公网尚未部署新路由。已读到的旧公网 FastDL 返回 200、A2S 返回 `cs_assault`/25人，只证明旧下载与游戏服务可访问。窗体预览如实显示新状态接口暂不可用。不能宣称公网自动更新或玩家真实入服已经验收。

## 复现自动检查

在仓库根目录的 PowerShell 7 使用 .NET 10 SDK，目录 `tests-repeat` 应尚不存在。没有启动 CS，也不需要修改原游戏安装。

```powershell
$env:DOTNET_CLI_HOME = "$PWD/.tools/dotnet-home"
$env:NUGET_PACKAGES = "$PWD/.tools/nuget-packages"
dotnet build tools/client-launcher/tests/LauncherTests.csproj -c Release -m:1 `
  -o "$PWD/build/client-launcher-20261101/tests-repeat" `
  "-p:BaseIntermediateOutputPath=$PWD/build/client-launcher-20261101/tests-obj/" `
  "-p:MSBuildProjectExtensionsPath=$PWD/build/client-launcher-20261101/tests-obj/" `
  -p:UseSharedCompilation=false
dotnet build/client-launcher-20261101/tests-repeat/LauncherTests.dll `
  "$PWD/build/client-launcher-20261101/tests-repeat/fixture" `
  "$PWD/build/client-launcher-20261101/assets-01" `
  "$PWD/sandbox/cs-client-b/Half-Life" `
  "$PWD/build/client-launcher-20261101/release-02/launcher-public/manifest.json"
ctest --test-dir build/client-launcher-20261101/http-tests-01 --output-on-failure -j1
```

完整包用例需要本机生成的安装包和隔离运行目录；只从公开源码重现时，可省略后三个参数运行不依赖真实游戏资源的事务用例。旧 tests-01 首轮异常类型断言失败已保留，修正后 tests-02 的 23 项、tests-03 的 25 项和最终 tests-04 的 32 项分别记录，不覆盖早期失败。
