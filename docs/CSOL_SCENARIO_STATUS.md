# CSOL 大灾变开发状态

2026-10-29：这是源码开发检查点，尚不是可完整游玩的灾变发布版。首测地图为穷途末路 `zs_deadend`；第一季逐图、BOSS、完整通关和多人验收仍未完成。

客户端采用独立 MetaHookSv 插件 CSOLSupport，服务端采用配套 ReHLDS / ReGameDLL_CS；AMXX 负责模式规则与管理员菜单。普通 CS、Zombie Plague 和灾变按模式隔离。游戏模型、地图、声音、字体及 DLL 不随源码仓库分发，需要使用者提供合法资源。

## 本批实现

- 接入原地图点位、波次、普通怪控制、伤害和死亡服务、玩家升级与阶段推进；管理员难度设置在下一次完整载图生效。完整 BOSS 与最终结算仍有未接部分。
- 在灾变模式关闭 SyPB 自动补员，防止缺路点反复刷屏；这不代替灾变怪物 AI。
- 将 MDL / SEQ 转换元数据绑定到引擎缓存的实际加载代次。客户端和服务端在选择、混合与骨骼采样前检查轨道和帧，包围盒计算保持全轨道严格校验。
- 保留 `zombi_host` 的全部 174 个动作编号。138 个本体动作通过校验，36 个不兼容外置动作保留原字节、明确标为不可采样；必须显式启用受保护的加载策略，选择这些轨道时拒绝进入原采样器。没有猜测骨骼映射或替换怪物。
