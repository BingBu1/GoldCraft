## 源码与自动化结果

新增 `shotgun_weapon.hpp/.cpp`，组合已证的 870 装填、射击、机瞄、派生帧和八霰弹弹道。逐壳装填不进入 CS 杂志式 `m_fInReload` 完成路径；人物动作使用已支持的 CS/CSO Shotgun 动作计划，显示与音效仍需宿主提供真实消费者。

`build/cof-shotgun-sdk-20261117-07/receipt.json`：实际 SDK 65,469 检查通过；完整原 fidget 指令 7,200 场景通过，覆盖 59 原指令，658 个实际输入在运行前后 SHA 一致。空、截断、额外和错误对照文件均正确失败。包含八霰弹调用、逐发装满、三种收尾、攻击打断、扩弹至 2048、备弹耗尽、切枪后抛壳、换模保留插弹/pump、库存生命周期、pending 退瞄装填、玩家推搡及死亡/serial/端点取消。

回归发现并修正：pump 发生在收枪之后时，不应再次覆盖玩家当前武器的音量与闪光状态；现在只在原射击位置写入，抛壳仅消费抛壳数据。该修正有专门的切枪后测试。随后审核发现，技能可在两次武器帧之间修改原生弹药；库存快照现在读取原生 clip/reserve，避免回滚发布旧缓存。补充 `PREEDIT-live-ammo-snapshot.json` 在修改前冻结；75/2000 发的实际 SDK 回滚用例通过。

前三轮真实编译失败分别为序列类型 include/QString 比较、缺少 BeforeWeaponDrop 虚方法、遗漏玩家动作链接依赖，记录保留于 `-01`、`-02`、`-03`。`-04` 首次通过；`-05` 增加抛壳副作用修正，`-06` 增加分配检查，最终 `-07` 增加技能弹药快照回滚；不把失败标为通过。
