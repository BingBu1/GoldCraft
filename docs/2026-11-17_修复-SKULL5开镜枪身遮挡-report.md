# SKULL-5 开镜枪身遮挡

SKULL-5 一级开镜仍显示枪身、二级开镜中心全黑。已确认移植缺少原版的开镜视模隐藏规则；第一版只补这条规则后，用户确认二级仍全黑。因此不能把枪身隐藏当作二级黑屏的完整修复；后续继续处理二级特有的原生镜框。

## 修改前证据

所有模块均为工作区内的 PE32/x86 副本，地址均为 VA：

| 模块 | SHA-256 | 相关证据 |
| --- | --- | --- |
| 原 CSOL client.dll，基址 01900000 | f4145136edbd229c219ea793bb3a6dcacea0b406ccc1e610138abbb8063bcbfd | Studio 接口 02A4AB90 → 回调 02A45570 → StudioDrawModel 02ACA500；隐藏门 02ACA9BD–02ACAA4D |
| 原 CSOL hw.dll，基址 37100000 | c7bddfda93c2e0877ea126a15a318b83cce74c59bb95e38a7301b08033ac7783 | SKULL-5 注册 37A7CC3B 传入 00018097，构造器 37A77970 将标志写到武器记录 +64 |
| 匹配宿主 CS client.dll，基址 10000000 | b434b1c09b10b011be6c42e4154955da0c3ca46e95746988ebea1aa316a2a9f2 | 接口 1004D380 → 1004A790 → 10066B50；10066C35 起按 v_awp/v_scout/v_g3sg1/v_sg550 模型名隐藏 |

原 CSOL 先识别当前实体是否是第一人称视模，再在 FOV < 90 且当前武器记录存在时检查 +64 的 80h 位。命中后恢复临时镜像和渲染状态，返回 0，跳过该视模的后续绘制与事件处理。SKULL-5 的 18097h 包含此位，因此 FOV 80 和 35 都隐藏枪身；普通人物和世界模型不属于此门。

宿主 CS 的名称判断不认识 v_skull5，因此扩展武器不能依赖原生名称分支自动隐藏。当前移植此前只接了镜框，没有补这条 Studio 可见性规则。

原中心 SPR 和圆弧 TGA 已与本地 B 的对应资源逐 SHA 核同：sniper_scope.spr 为 eb65dd96208e029c9c92d4de5b74a2654f7e7d5ee29659a63296eb025cbf7f72，scope_arc.tga 为 2a35485fc918c1578471bcce31ecf68df1304f22b84cb8881f55132c0c1f4c4f。本轮不修改资源、倍率、弹道、镜框几何或透明参数。

私有原始指令、反编译、完整上下文和逐字节复核保存在 analysis/skull5-scope-20261117。PREEDIT.json 在生产修改前记录原件和源码身份；evidence-verification.json 重核两个隐藏门以及原 HW 注册、构造和索引范围，共 690 字节。首个 IDA 服务概览超时、初始未分析函数的反编译失败和截短输出均保留，最终结论使用核同的原始字节与有界指令窗口。原件、数据库和反编译正文不发布。

## 证据 → 行为 → 实现

| 证据 | 行为 | 项目位置 |
| --- | --- | --- |
| 原 HW 18097h + 原 client 标志位 80h 消费 | 武器声明开镜隐藏资格 | native/csol/client/weapons/weapon_module.hpp、skull5.cpp |
| 原 client FOV/实体/当前武器门 | 仅隐藏当前开镜武器的第一人称视模 | native/csol/client/weapons/weapons.cpp、weapons.hpp |
| 原 Studio 提前返回及恢复顺序 | 在插件临时手模、材质和事件状态修改前返回 0 | native/csol/client/plugin.cpp |

这是公开 SDK Studio 回调上的宿主适配，不套用原版对象偏移。不改写模型指针或用户 CVAR，不保存需要跨切枪恢复的隐藏状态。使用现有按 ID 索引的武器注册表，新增路径为常数次内存查询和视模指针比较，无分配、磁盘、网络或 GL 查询。实际 CPU/GPU/帧时间尚未采样，不将代码成本分析视作实机性能验收。
