# M 玩家购买与管理员两级入口

M 首页按用户要求改为第1项“购买系统”、第2项“管理员菜单”。普通玩家只看到购买入口；服务端在显示和提交管理操作时分别校验权限。原八项管理动作及持久玩法设置保留在二级管理页。

## 实际购买链

修改前核对匹配 AMXX `engclient_cmd`／`UTIL_FakeClientCommand`、ReGameDLL `ClientCommand` 的 `buy` 分支，以及客户端 `buy_menu.cpp` 的 VGUI／ShowMenu 消费者。首页先销毁自己的 AMXX 菜单，再重新检查当前模式、加入状态和 userid，最后只派发一次固定 `engclient_cmd(id, "buy")`。

该路径进入真实 CSOL 购买菜单，并保留服务端购买区域和存活限制。没有发送缺少 request 的内部目录命令，没有替代实际购买流程。尚未接通的盲盒与熟练度状态文字已从首页移除；对应玩法继续实施，不计为完成。此首页属于用户自定义，未宣称原版 CSOL 布局还原。
