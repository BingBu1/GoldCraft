## 实现和验证

沿用现有私有解码副本、文件释放与候选表整批提交。`MapTables` 只存不可变路线目录；本次未接 `InitializeChaosRooms`、TRG 路线覆盖或出口跳房间。保留原文件中字节和路由顺序；事务失败保护属于宿主适配。

父核路线核心交接 363 份引用。核心 5 个编译单元、941 项检查全部通过，其中 445 组执行原 MP 指令对照。详见 `build/chaos-lifecycle-20261105/parent-core-review.json`，不是完整游戏 DLL。

资源回归 `build/chaos-resource-20261105/loader-02/result.json`：实际 14 个 C++ 编译单元按 x86、C++20、O3/ThinLTO、AVX2、精确浮点编译链接，普通配置 321 项、RRR 事务 107 项，零失败。覆盖缺文件/错误长度/空内容/错误结构/嵌入 NUL、旧五表及地址不变、修复后整批提交、同图 subtype 切换、清理以及文件分配精确释放。RRR 使用原加密文件，其余四表使用合成输入，所以这不是原 Chaos 整图加载验收。

同一冻结源和 ABI 仅撤去 RRR 加载分支，原回归出现 3 项失败，RRR 回归出现 3 项失败，见 `missing-rrr-negative-02`。没有混用新头文件和旧对象构造失败。

为防止夹带未审候选，另以 main `7ad78a4` 加本次精确文件生成 `selected-source-01`，排除 MAP_TRG、其它 BOSS、准入与 Session 改动；`publication-loader-01` 再次实际 14 TU 编译链接，321＋107 项通过。该快照的输入身份保留在结果中。首次 runner 误取 CMake 包装器作链接器的失败记录保留，后续明确选择实际 `lld-link.exe`。
