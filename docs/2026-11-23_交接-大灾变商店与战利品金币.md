- 三种盲盒均可在买区外购买。枪械直接补满弹匣及备弹。CSOL 盲盒 30,000，交付主副各一把。买区内补满两把枪 2,000，满弹免扣。提灯 1,500，照明弹 300。30 元清洗当前携带武器和手臂，清洁时免扣。16,000 元只购买一次选购资格，消费后不可重复使用，CSOL 武器被拦截。
- 僵尸正午、黄昏、永夜的地面移动峰值为 200.00001、200.00001、220.00001。用原生 Think 后置回调取样，地图传送带施加推力前的基准和外力样本分别观测。传送带作用时录到 583.747。实际击杀奖金为 50，伤害返金单独记账。
