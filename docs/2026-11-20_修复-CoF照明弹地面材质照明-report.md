# CoF 落地照明弹的地面材质照明

永夜《穷途末路》的落地照明弹使用半径 220 的 CoF 原色点光，地砖和墙面参与 GoldSrc 材质光照。

## 恢复 CoF 原色与落地照明范围

用户要求恢复原范围、撤去额外橙色并保留材质照明。原 CoF 世界实体处理器 VA 0x100602DE 选择燃烧中的照明弹，0x1006034E 使用半径基数 220。0x10060302 与 0x10060314 取两个随机值，0x10060375、0x1006037D、0x100603A3 分别写红、绿、蓝通道。按原顺序取色后，红色为 1.15 加上 −0.5 至 0.5 的变化，绿色和蓝色分别为 0.2 和 0.1 加上同一个 −0.05 至 0.05 的变化。修改前重新核对了 x86 模块完整 SHA-256、209 字节原指令和三处浮点常量。

落地光使用固定半径 220，以继续复用静态地图阴影。手持、飞行和落地共用原色计算，在 GoldSrc 原生点光入口量化为 RGB8。光仍在材质阶段作用于地砖和墙面。服务端火伤半径 96，每秒 5 点直到熄灭。

单 B 在永夜《穷途末路》购买照明弹，在 4 号位取出、点燃、投出并复拍同一块地砖。服务端确认已落地后固定弹体与相机。表中是 8 位显示亮度，使用与上次相同的 BSP 可见性筛选和方向中位数。

| 距弹体的地图单位 | 上一版 520 | 原色版 220 | 原色版熄灭后 |
| ---: | ---: | ---: | ---: |
| 32 | 96.7 | 62.8 | 1.0 |
| 64 | 76.8 | 49.0 | 1.0 |
| 128 | 60.0 | 35.3 | 1.0 |
| 192 | 56.1 | 20.2 | 1.9 |
| 256 | 62.6 | 2.0 | 2.0 |
| 320 | 46.7 | 1.8 | 1.8 |

连续 391 个实机渲染帧中的同一盏光均为 220 单位。实际红、绿、蓝通道范围分别为 166–255、38–64、13–38。在弹体 128 单位以内，原 `cugrounda` 贴图与实机的 6,854 对邻近像素红通道差值相关系数为 0.894，纹理平均亮暗差为 25.0 级。熄灭后拍到五帧，其中前两帧的位置与视角一致，两块固定墙地的 44,010 个通道值与投掷前逐项一致。这两帧纳入熄灭后对照，其余三帧出现位置偏移。服务端在 235.7 秒观察到同序号实体原地自然熄灭。

完整 x86 客户端采用 C++20、O3、ThinLTO、AVX2 和精确浮点。重编装备文件，核对 448 个编译依赖、164 个链接对象和静态库。首轮校验把已经替换的旧缓存对象也纳入核验，重新按实际链接响应文件逐项校验后通过。颜色观察器首轮因枚举无关显卡模块失败，改用已匹配 B 可执行文件和 Renderer CodeView 的只读观察器，在同一枚弹的燃烧期取得上述样本。入服前 326 项 HUD 与 292 项客串资源实际 HTTP 校验通过，B 实际 v4 缓存 3519/3519，永夜 HUD 已绘制。此次连续 783 个相邻 Renderer 帧间隔的中位数为 10.0 毫秒，P95 为 13.0 毫秒。常用沙盒专服 327 项 HUD 预检通过，实测版 `c2c0c1cf72040dcdced005ce1f76be7d57047146ea2fdfc7ec8017b8c4b99acf` 已装到常用 B。正式服分发、多人和多弹同屏仍待验。

实测回执位于 `build/cof-flare-radius-20261120/`，原始帧位于 `build/cof-equipment-live-20261119/burn-live-famas-08/`。

## 早期材质修复的来源与实现

- CoF x86 原版客户端 SHA-256 为 `d2a04641b301804f6f449aa68265042b13adc360925b80033d417ec9f38c9c00`。映像基址 0x10000000。世界实体消费者 VA 0x100602DE 检查燃烧效果 165，使用实体键，VA 0x10060334 的高度常数为 5，VA 0x1006034E 的半径基准为 220。手持分支 VA 0x100B1321 使用附件。服务端 x86 hl.dll 的 SHA-256 为 `0036b91c01e92ed205513f52563053a55a66a32d257efb5f476b8f1f3dde0e63`，世界燃烧处理 VA 0x1003DA40 的 443 字节与归档逐字节核同。
- 宿主服务端实际落地时把燃烧弹从 SOLID_BBOX 改为 SOLID_TRIGGER，并重新链接。实体状态通过模型、body 和网络传输的 solid 识别。自然熄灭时同一实体的 body 从 1 变为 0。测试中未使用客户端 onground 判断。
- 此前为提高地面亮度，实验版本把落地半径放大到 520，并人为选用了暖色。光心保持实体上方 5 单位，RGB 为 255、151±3、84±3，色彩轻微变化，半径固定。Renderer 累积点光后将照明乘以当前地表材质。静态和动态阴影请求为 256 像素。光键在客户端独立于玩家手电。熄灭、离开可见集和地图重置会释放对应灯光记录，回收时核对实际引擎灯键。
- 持有、飞行和提灯沿用原有消费者。生产变更集中于 `native/csol/client/weapons/guest_cof_light_equipment.cpp`。本地 AMXX 验证插件为 `amxx/tests/cof/cof_live.sma`，使用正常购买、点燃和投掷，先验证服务端已经落地，再固定相机和弹体以重拍。旧版与材质版使用同一专服 MP。
- 私有原版记录在 `analysis/cof-weapons-20261111/lighting-equipment-20261119/ground-illumination-before.json` 和 `ground-material-before.json`。

## 早期 520 单位材质光的永夜实机对照

单 B 在永夜《穷途末路》复拍了微弱的原灯、直接叠色的增亮实验和最终的材质点光。三组机位、落地点、反投影矩阵均已核对。地面像素只纳入通过世界 BSP 视线检查的采样点。亮度为 8 位显示空间的加权 RGB 值，取每个距离的方向中位数，再取连续帧中位数。不同距离可能落在颜色不同的砖面上。

地砖是 `cs_havana.wad` 中 256×256 的 `cugrounda`。按实际 BSP 纹理坐标和画面矩阵投影到同一地面区域，选取原贴图红通道差值至少 12 的 7,109 对邻近像素。直接叠色版与原纹理的差值相关系数为 0.26，最终版为 0.92。按原纹理亮暗方向取实机红通道差值，平均对比从 1.2 提升到 27.5 级。画面可辨认地砖的铺设方向、暗砖缝和墙脚饰条。

最终版服务端在游戏时间 106.6 秒记录了落地状态，在 219.1 秒观察到同序号、仍在原位置的实体自然熄灭。熄灭后的相机也按原位置重拍。原有伤害仍使用半径 96、每秒 5 点、熄灭停伤的服务端规则，同一 MP 已有独立的实机伤害与隔墙检查。[火焰伤害记录](2026-11-19_实现-CoF照明弹火焰伤害-report.md)

## 早期材质版的构建与部署

x86 客户端采用 C++20、Clang O3、ThinLTO、AVX2 和精确浮点。共享工作区同时有其他原版武器预测变更，交付构建按改前 SHA-256 重新编译 11 个受影响的对象并复用核同的对象，总计 164 个链接输入，恢复常用沙盒的既有武器版本。最终客户端为 `523542dcf5c628445b8e81d29dd7e3b0830ab808c071f92ff12ec029433c0969`。新旧 DLL、配套 PDB、隔离服实际加载与常用 B 安装均单独核同。

隔离服通过 326 项 HUD 预检，292 个客串下载文件逐一进行 HTTP 哈希校验。最终 B 的 v4 缓存挂载 3519/3519，永夜 HUD 和实际购入第 4 栏照明弹均可观察。专服登记的十把 CoF 枪也存在。本轮实机购买对象为照明弹，十枪报价及九枪逐件购入的覆盖范围见 FAMAS 记录。常用沙盒专服通过 327 项 HUD 预检，本次只向 B 安装客户端 DLL 和 PDB。

最终版同机位采集了 623 个连续 Renderer 帧间隔，中位数 11.4 毫秒、P95 为 21.4 毫秒，属于整机实景采样。多名真人、多枚照明弹同时燃烧、移动遮挡和正式服分发仍待验证。静止点光使用固定半径保留静态 BSP 阴影缓存，每帧遍历上限 32 个已发光实体，装备代码不在绘制中读取贴图或配置文件。

本地对照和数值回执见 `build/cof-flare-ground-20261120/`。实机原始帧位于 `build/cof-equipment-live-20261119/burn-live-famas-03`、`burn-live-famas-04` 和 `burn-live-famas-06`。
