## 首次失败与最终修正

完整保留各次输出，未将失败记录覆盖为成功：

- `live-server-01`：执行器错误地把 SDK 目录名 358 当运行版本；没有开始生命周期测试。改为固定实际版本、精确 DLL SHA 和加载路径。
- `live-server-02`：测试夹具在 private object 创建前使用 ReAPI entvar native，产生原生无效实体错误。按已有 ready fixture 的真实契约改为 Fakemeta `pev/set_pev`；没有改变生产 GameDLL。
- `live-server-03/04`：晚加入已自然出生，但测试错误要求首通知至少 2 秒或必须两条通知。1.5 秒实际延时允许只发一条整数通知；改为至少一条，加独立真实时钟下界。
- `live-server-05`：37 项通过，团灭观察覆盖真实截止后 4.533 秒；这不是生产失败。最终第 06 次将观察窗口延长到真实截止后 5.014 秒，再次 37 项通过。

执行器同时修正为只接受阶段级最终结果，不能把单项 `check=... result=PASS` 当整组完成；新增 AMXX 错误立即终止，并仅读取本次新增日志字节，历史错误保留。
