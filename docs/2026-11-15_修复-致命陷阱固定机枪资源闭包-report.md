# 致命陷阱固定机枪缺资源与下载闭包

用户报告接入地图启动时出现 `Mod_LoadModel: models/shell762.mdl not found`。实际地图为 `zs_decoy`，场景目录 ID 113；BSP 中有七个 `mount_weapon`。既有机枪实现会预缓存这个弹壳模型，而先前生成的 17 文件资源计划没有应用到主测试服。

## 原版证据与修复边界

- 原 MP：x86、基址 `10000000`，SHA-256 `39f962f34816411e615f01e5279d914204f7fd07c5a5112b0b303acafe0308b2`。
- 原 x86 client：SHA-256 `f4145136edbd229c219ea793bb3a6dcacea0b406ccc1e610138abbb8063bcbfd`。本次重核实际样本身份，复用机枪调用链记录。
- IDA 再核 `1114C8D0..1114C909`（RVA `0114C8D0`）：完整 16 指令，声音 `weapons/Mountgun_1.wav` → `models/shell762.mdl` → 原引擎事件名 `mountgun`；64 字节与原 PE 逐字节一致。私证为 `analysis/csol-mountgun-20261114/repair-20261115-precache-ida.json`；已有 Deploy／事件消费者见 11-13 致命陷阱报告。
- 本次不修改机枪伤害、AI、动画或原版时序。`events/mountgun.sc`、下载清单和字体方案准入是既有 GoldSrc 宿主适配的配套修复。
- 原 `overviews/zs_decoy.txt` 明确引用 `overviews/zs_trace.bmp`；ReHLDS `PrecacheMapSpecifiedResources` 还会登记 `<地图名>.bmp`。使用原图片的精确字节提供宿主别名，保留原描述和图片引用。

## 已修改及已应用

1. 17 个机枪模型、材质、纹理、事件、声音和 HUD 文件已只新增部署到本地主服及独立测试服，未覆盖玩家客户端资源。
2. 全表审计另外发现主服缺少两个特效材质 JSON 和概览别名，已补齐；两个材质逐字节核对原 `materials/common.json` 经现有转换器的模型局部输出。主服合计新增 20 文件。独立服另补其缺少的既有计时器字体方案。
3. `tools/csol_map_entity_resources.py` 从实际 `CMountgun::Precache`／`CCSOLZeCounter::Spawn` 及其常量头读取依赖，不维护另一份机枪文件列表；未解析的预缓存表达式直接报错。地图资源计划、独立闭包审计和完整服务器包预检共用它。
4. `ServerPackageMaps.py` 跟踪原概览 `IMAGE`，并为 ReHLDS 所需的单 BMP 别名绑定真实来源；缺少原图时拒绝生成包。资源计划保留目标名与来源名的区别。
5. 修复严格 `reslist` 解析器不能识别缺失文件所打印的 `-0.00K`；仍检查总数、连续序号和实际文件，不能把解析成功当作资源存在。
6. 新计时器方案 `resource/csol/zecounter/v1/ZeCounterScheme.res` 原先被 HTTP／客户端 VFS 白名单遗漏。两端只新增这一个已发布路径，其他任意 `.res` 继续拒绝。

以上代码在冷准备、下载请求或打包阶段执行；没有新增逐帧、逐怪物或绘制工作，也没有跳过资源校验。本轮没有宣称整图性能提升。
