## 编译与验证

运行于 Git Bash，需私有原样本及 PREEDIT；输出必须为新的工作区 build 目录：

```bash
python -B tests/cryoffear-muzzle-flash/run.py \
  --environment build/csol-season2-trace-20261109/compiler-env.json \
  --sample analysis/cof-weapons-20261111/samples/client.dll \
  --shotgun-proof analysis/cof-weapons-20261111/shotgun-20261116/integration-20261117/PREEDIT-muzzle.json \
  --output build/cof-shotgun-client-muzzle-reproduce
```

P345、Revolver、VP70、TMP、MP5、M16、G43、Shotgun 均为 1,145 场景、0 差异；既有 Glock 世界尾部边界继续覆盖。原指令由 Unicorn 执行，骨骼变换和宿主服务为受控边界，不等于真实渲染。编译器发现真实依赖，原样本、证据归档、工具链及输入前后核同；保留 PE32、C++20、O3/ThinLTO/AVX2、precise FP、禁止 FMA 合并。

第一次运行因依赖发现同时传 `/c` 和 `-M` 被 WX 拒绝，失败保留在 `build/cof-shotgun-client-muzzle-20261117-01`；仅预处理命令移除 `/c`，正式编译选项不变，第二次完整通过。没有重启已经运行的作业来伪造成功回执。
