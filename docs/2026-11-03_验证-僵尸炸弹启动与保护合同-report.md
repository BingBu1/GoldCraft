## 原合同补核

完整地址和细节在 `followup/contract.md`。应特别保留以下边界：

- Touch 忽略 owner。仅 classname 精确为 `func_breakable`、真实 CBreakable、rendermode 非零、`blockgrenade` 为 false 时，三分量 velocity 乘 -2 并返回。后续实体补证以原 entvars 保存表确认 +0x160 是 rendermode；早期报告误写为 takedamage，已更正。此处不附加可受伤资格。
- `pev.dmg==999` 是种类标记，实际伤害来自 `pev.health`。伤害零跳过防护、Addon13 与 TakeDamage，但继续击退及消息。
- 非零伤害顺序为 kind15 配件保护、双精度伤害/力减免、Addon13 免疫、TakeDamage、速度、ScreenShake、MPToCL3。TakeDamage 普通返回 false 不代表撤销后续；实体或生命代失效才取消。
- kind15 收集受击者当前枪和携带枪被动配件，不读取传入的攻击者/inflictor。原 `_time64(NULL)` 低 32 位种 MT；以乘 100 的高 32 位取 0–99，低 32 位小于 96 重抽；概率严格大于样本，选最大正 duration。不能套现有 [0,1) 的 WeaponAttributeRandom。
- until 精确为零才尝试新保护。ratio 用 double 的 param3×0.01；减免是 `float(double(value)-double(value)*ratio)`，没有 ratio clamp。普通更新在 now≥until 时清期限；未找到独立死亡/Spawn 清零，不额外发明。
- Addon13 属于 component12，不能与人物 cloak key12 混淆。激活且等级正才取引擎随机 0–99，概率严格大于随机数才免伤免推并跳消息。
- 炸弹用原 11409970 冲量入口。最后参数是 **整数 minimum=1**；前一个布尔来自友伤/自身条件。mode15 不经过现有 114ECF00 helper 的 actionKnockback/blocksKnockback 拒绝门。
- ScreenShake 原 mode15 是 MSG_ONE 的 short 40960/8192/25600；不使用会过滤空中玩家的 UTIL_ScreenShake。MPToCL3 是一次性的 yaw/pitch 摆动，各自从 CRT rand 得到正偶数 10–18 或负奇数 -11–-19，消费后清零。
