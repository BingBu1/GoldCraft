# 2026-11-23 纯 CS 大灾变与 CoF 累计服务器更新 R2

当前包为 `GoldCraft-Server-Update-20261123-CoF-R2.zip`，适用于已部署大灾变基础资源的 CS 1.6 服务器，包含 ShortCache-R3 和首版 CoF 的游戏更新。

若首版停在第 113 行，提示 `Unknown existing file; preserved without overwriting: cs/hlds.exe`，可关闭旧窗口，直接安装 R2。首版在停服及写入前做了这次检查。R2 沿用服主原有的 `cs/hlds.exe`，继续逐项校验 `swds.dll`、`filesystem_stdio.dll`、`mp.dll` 和其余受管文件。

1. 将 R2 解压到服务器目录外的全新文件夹，双击其中的 `Update-Server.cmd`。自定义路径可传入 `-TargetDirectory "D:\我的服务器"`，指向含原 `Start.cmd` 的目录。
2. 预检完成后，更新器自动停止运行中的 CS 专服，备份并安装变更，再用原启动脚本重启。重复运行时已是最新版会直接结束。预览使用 `-Plan`，撤回本次安装使用 `Restore-Server.cmd`。
3. 玩家退出 CS，使用原冰桑启动器启动，获取签名序号 `2026112301` 的配套文件。
