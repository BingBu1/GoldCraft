## 源码

`native/csol/sequences.cpp` 先从不可变输入验证、量化全部原动画，保留四字节末端可读 padding，再检查原动画与旧描述符联合区域能否容纳结果。

资格检查遍历骨骼、控制器、碰撞盒、附件、事件、pivot、纹理和 skin、body/model/mesh、顶点/法线、骨索引数组、完整三角命令流、过渡表。所有仍用范围必须与复用区域不相交；未知 automove、sound、deformation、group 数据及非零未明 mesh 字段回退原追加布局。所有尺寸计算和额外遍历受输入长度/工作量预算限制。

独立审查发现并修正：必须检查最终全部 MDL **及追加 SEQ** 的 automove 和 transition 节点。宿主 `FindTransition` 直接用 entry/exit 计算过渡表索引，只检查表声明跨度不足以保护被读取字节。节点越界、负值或非零 entry 配零 exit 均使本模型回退，不清除字段、不增加新的模型拒绝路径。最终描述符、纹理搬移与 SequenceSafety 发布规则保留。
