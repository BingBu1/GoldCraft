# 下载中断恢复与换图进度

本阶段修复两条下载路径对短暂 HTTP 故障过早放弃的问题，并把资源校验接入原生加载窗口。源码、完整 DLL、网络／VFS 与安装回滚已验证；尚未部署到本地游戏或正式服，画面和公网体验仍待验收。满体力连跳延迟仍开放。

## 范围与证据

人类要求修复下载中主动 Drop、无法继续下载，以及换图长期停留在“建立网络连接”空条后直接入图。本轮只进行项目源修改、工作区编译、隔离文件系统／loopback HTTP 测试和签名打包；没有启动 B、操作正式服或修改受保护 Steam 安装。私有取证范围及时间线位于 `analysis/download-drop-20261115/scope.md`、`timeline.md`。

## 发现与实现对应

| Finding | 证据／置信度 | 实现位置与状态 |
|---|---|---|
| F1：短暂服务故障过早结束下载，n/a_re | E4、E5，高 | `native/client/resource_download.cpp`、`native/parallel_download/transfer.cpp`：暂时性 408／429／500／502／503／504 及网络连接类错误采用有限退避；最多 12 次、首次失败后最多 60 秒恢复预算，并受既有请求／总时限约束。SHA、长度、404 等错误不改成无限重试，不跳过验证。源码／网络检查通过，公网待验。 |
| F2：零正文错误响应掩盖 HTTP 503，n/a_re | E4、E5，高 | SHA 路径先分类非 200 状态，再验证成功正文长度；保留早期候选误判为长度错误的失败记录。 |
| F3：重试等待不能仅靠 WinHTTP 轮询取消，n/a_re | E5，高 | `native/include/goldcraft/async_download.hpp`：使用 Asio cancellation slot/signal，中断退避计时器；信号只在 IO executor 发出，固定 16 槽快照对应并发上限。保留请求关闭 fence、旧会话隔离、取消与析构检查。 |
| F4：加载窗口没有校验阶段的进度范围，n/a_re | E1—E3，高 | `native/client/resource_bridge.cpp`：所有权暂停后，按 Session 的实际 checking／downloading／verifying 计数初始化、推进 GameUI；恢复前接回原生范围。直接调用已证 GameUI 接口，正常主帧绘制，最多 30Hz 且未改变的计数不更新。每次 UI 回调后复查连接、token 和阶段；刷新阶段不伪造已完成文件数。配套目录新增精确 GameUI 全局指针。 |
| F5：资源失败直接无说明断开，n/a_re | E1、E5，高 | `resource_bridge.cpp`：正常返回所有权清理后，排队内部引擎命令显示具体 Host_Error；取消或更换连接使旧命令失效。避免清理栈内 longjmp。 |

P1（callflow）：完整清单 → 暂停资源消费者 → 原生窗口显示实际校验计数 → 有界八路下载／恢复 → 最终全量 VFS 再解析 → 恢复原生加载范围 → 资源所有权提交 → 继续原生预缓存。取消／失败则清理事务；只有仍匹配原连接的失败才进入引擎错误命令。

`native/parallel_download/plugin.cpp` 的刷新阶段仅显示“正在加载资源…”，避免把清单总数误当模型加载进度。没有为模型循环增加消息泵，也没有添加假进度延时。

## 交付与未完成边界

更新器支持以已发 Hotfix1 为基线，按 SHA 复用封存的客户端核心；签名 bundle 必须与既有 release 一致。新增两个客户端 DLL 及配套完整目录通过原受管启动器更新，补带此前六脚本；不要求玩家手动覆盖错误资源。包中不包含未证明的跳跃修复。

正式交付 ZIP 与签名升级结果在完成封存后追加。本轮不把本地文件系统／loopback HTTP 成功称为真实公网修复；断网、永久缺件、用户主动取消、原生 HTTP 的预期断开仍需区别。当前正式服 MP／引擎身份已核同，不能再归因于用户加载旧 DLL；不再要求服主重复运行诊断脚本。

仍待：这版实际换图画面／公网下载及多人；满体力连跳输入—usercmd—预测—落地链；其他未完成大灾变目标保持原范围。
