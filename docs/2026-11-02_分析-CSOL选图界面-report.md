# CSOL 选图界面与通关投票

本阶段依据当前 CSOL GameUI 的实际消费者移植地图卡片、字体、边框和滚动布局。服务器权威的通关投票是 GoldCraft 的新增规则。资源存在不代表地图可玩，候选必须通过对应地图的服务端准入。

## 已核实的原版界面

样本为工作区研究副本 `GameUI.dll`，PE32+/x64，SHA-256 `bd31fdf1c4ee795bf24de64ab28a6fcf0671c86db485ff3d563cbd505aa48770`。本样本只作为当前界面设计依据；其地址不能用于项目的 x86 客户端。原安装只读，IDA 只写独立研究数据库。

当前消费者是 `CMapSelectDialogV2` 和 `CMapListPanelVer2`。保留的旧 `popup_mapselect.res` 并非这版菜单的布局依据；旧 Age 字体也不能代替实际 `GetFont("Default16", false)`。原 scheme 的 Default16 为 DFYuanW9-GB、16 高、weight 0、抗锯齿开启、无阴影。

首组三张卡另有 x+4 的路径，不与一般列表坐标混用。地图特定变体可选择 `%s2_cso`，该字段并非所有地图通用开关。原背景使用 `resource/MapModeV2/ModeBg.bik`；当前项目不因此宣称已支持原版动态背景。

普通、选中、悬停分别使用以下九宫格，共27张原图均在解包 common 中存在：

- `resource/control/button_list/9/Button_List_*@n.tga`
- `resource/control/selected/Selected_*.tga`
- `resource/Control/Selected/Over_*.tga`

九宫格先取左上角素材的尺寸，将角宽高限制到面板宽高的一半，再设置四角、四边、中心的矩形；按原序逐片绘制。不能把选中框替换为随意描边或把边角随面板整体拉伸。

## 证据与实现边界

E-01：`analysis/csol-model-20261017/map-selection-20261102/byte-audit.json` 记录构造与两条卡片填充分支共8,069字节的原 PE/IDA 对照。F-01（静态已验证、高置信度）据此确定实际类、卡片布局及字体调用；实现位置为独立 CSOLSupport 菜单。

E-02：同目录 `round-table-ida.json`、`round-table-byte-audit.json`、`round-panels.json` 记录三表、虚表和27张素材的身份。F-02（静态已验证、高置信度）将原type0/1/10分别映射为普通/选中/悬停，禁止从文件名猜类型。

E-03：`round-layout-ida.json`、`round-paint-ida.json` 和 `round-render-byte-audit.json` 记录布局、绘制与高度初始化。F-03（静态已验证、高置信度）确认默认窗口高度510和九宫格尺寸规则。初始缺代码定义产生的短JUMPOUT结果保留但不作结论；补齐窄函数后重新生成伪码，并以原字节核对。

P-01（调用路径）：`CMapSelectDialogV2(180633700)` → 列表构造/卡片填充（E-01/F-01）→ `CRoundPanel(180802040)` → 类型表加载`180802B10`（E-02/F-02）→ 布局`180803860`/绘制`180803600`（E-03/F-03）。本地可重跑 `round_panels.py` 与 `close_layout.py` 核原样本及保存的 IDA 字节；研究目录和原始素材不发布。

投票核心已通过161项检查：32槽真实userid、换票、断线撤票、槽位复用、晚加入、过期请求、截止与平票，以及有界消息解码。项目默认20秒，可配置10–120秒；这些不是逆向得到的CSOL常量。服务端只接受已验证地图，排除当前图，没有候选则保留自由游玩。

时序：先核当前消费者与8,069字节；再核九宫格资源和绘制；随后补根窗口默认高度。当前客户端展示、专服接线和资源导出仍在实现/编译，尚未进行新菜单实机验证。其他第一季地图的实体、刷怪、BOSS和通关也尚未逐图验收，不能将161项投票组件检查算作地图通过。
