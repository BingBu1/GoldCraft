# 启动器符号目录配套遗漏

用户应用 11 月 7 日服务器累计包后，旧冰桑启动器 2026.11.01.6 启动游戏报
`CSOLSupport: unavailable matched engine symbol: CSOL_CRC32_ProcessBuffer`。
这是发布配套错误：新 DLL 与旧启动器内置的静态符号目录不兼容。
不是地图、模型下载失败，也没有证据表明用户基础引擎损坏。

## 根因与可核证据

- `native/csol/client/model_crc.cpp` 的 `InstallModelCrc` 在已发布优化版本中要求该函数符号。
- `tools/client-launcher/Updates.cs` 只接受内置核心白名单的 DLL；
  `Bundle.cs` 的安装校验仍逐项验证原 bundle 的固定资源。
- 通用 `tools/client-launcher/Publish-Update.ps1` 原本拒绝静态资源改变后沿用旧合同。
  累计包专用 `tools/current-server-update/Publish.ps1` 未执行此检查，仍用旧 bundleId 发布两份新 DLL。
- 从实际交付 EXE 只读提取的旧 `bundle.json` / `payload.zip` 位于
  `build/launcher-static-hotfix-20261108/old-exe`，提取身份见该目录 `extraction.json`。
- 父对话独立比较旧内置 payload 与当前 B：两份符号快照和两个索引不同。
  `goldcraft-cs` 增加 `UTIL_SharedRandomFloat`、`CSOL_ClientCRTRand`；
  `goldcraft-precache` 增加 CRC 及 HUD/SPR 等 12 项。已有记录没有修改或删除。
  结果：`build/launcher-static-contract-20261108/old-new-catalogs.json`。
- 当前 B 的 207 份 JSON 及全部索引引用 SHA/长度一致；唯一 CRC 记录在
  `cstrike/metahook/gamedata/goldcraft-precache/goldcraft-precache-hl-10210.json`。
  宿主引擎 SHA-256 `9ba9a2db5e07598fd59afa35507a98c86162e4e15b3835177b78c11842cd2295`、
  CRC64 `6ef7192cd8254e2d`，CRC RVA `0x1bc450` / 长度 `0x1ab`。
  实际 PE 中对应完整指令字节与已保存 `native/csol/sequence_engine_10210.json` 一致。
  见同目录 `catalog-audit.json`。本次不修改函数地址、游戏行为或未知引擎兼容范围。

## 防回归修改

专用发布器新增必需的 `-Bundle`、`-Runtime`，在签名和创建发布目录之前调用
`StaticContract.ps1`：检查原 bundle 与签名基线身份、核心文件集合、所有非核心运行资源
SHA/长度和基础游戏 SHA；新增但旧包未登记的 JSON 符号目录也拒绝。
许可证继续来自发行资源，不要求其存在于游戏运行目录。
固定资源变化必须重新制作启动器，不允许通过删除匹配检查或只放 FastDL 掩盖。

## 验证层级

- 实际 Windows PowerShell 5.1 执行生产预检：10 项通过，覆盖兼容 DLL 变化、
  符号改变/缺失/新增、shader 改变、引擎身份、bundle/core 集合以及路径逃逸。
  收据 `build/launcher-static-contract-20261108/receipt.json`。
- 实际旧 EXE bundle 对当前 B 被预检正确拒绝；首先报 `goldcraft-cs` 固定资源变化。
  `actual-old-bundle-rejection.json` / `.log` 保留结果。
  首次测试误传签名 envelope 而非解码 release，提前拒绝；未计入有效反例。
- 没有编译或部署 native DLL，没有操作本地运行沙盒、原 Steam 安装或正式服务器。
- 新单文件启动器、配套签名 manifest、小型服务器热修包及真实旧安装升级测试
  由主调度打包窗口负责；最终交付和真人启动结果须另记，不能把预检通过视为入服验收。

共享文档建议：登记“修复 11 月 7 日 DLL/静态符号目录不配套；新版启动器和服务器
签名合同必须成套应用，远端真人启动仍待”。大目标仍保持用户的暂停状态。
