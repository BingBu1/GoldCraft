# 大灾变永久模型血迹

近距离枪击每次命中能出血的灾变僵尸，手臂与实际开火的枪各叠加一层随机飞溅。每层有四组大小、方向和落点不同的血花，原来的溅点留在原处。同一发的多弹丸与穿透共用一次溅射。每个表面能够累积 63 层，达到上限后保留最终覆盖。僵尸自己的受击血迹也逐步累积，并在实体可见期间保留。

手臂血迹随玩家在本图存续，重生与同图重玩后仍显示。同一把枪在手持、落地及换人拾取时始终带着自己的血迹。地图卸载、玩家离开和实体销毁是状态回收边界。僵尸池回收再借出时，新僵尸从干净状态开始。关闭模型血迹会隐藏已有血迹，重新开启后按原样显示。

## 管理设置

统一 `gameplay.json` 中的 `features.blood.enabled` 控制模型血迹，默认关闭。M 菜单的「管理员菜单 → 模型血迹」可即时开关并保存。溅射距离 `blood_splash_radius` 默认 128 GoldSrc 单位，设为 0 时只保留僵尸受击血迹。旧版 JSON 中的血迹寿命与上限字段仍能读取，在下次保存时自动移除。

## 运行路径

服务端通过真实弹道和伤害聚合确认命中与开火枪械。血迹状态按实体槽及序列号保存，僵尸逻辑复用命中后的出血分类。玩家和普通实体快照在 `fuser4` 的 28 位自定义增量中携带两组种子与击中次数。原生客户端会覆写本地玩家快照的 `iuser3`，改用通过实机核对的 `fuser4`。服务端与客户端同时更新才会显示新版血迹。

渲染端用六张游戏自带的 WAD 血花生成两组共 126 层的累积贴图。每个 GL 上下文准备一次，由两套 Studio 绘制路径共享显存，单个材质仍只采样一次。保留旧点并叠加新点，斑点有颗粒和深浅。原生 Renderer 对沾血的部分降低高光，手臂使用材质名识别并保持同一贴图的溅点位置。关闭效果时停用渲染查询。

## 2026-11-21 命中点血迹和近战沾血

开启模型血迹时，出血命中只在僵尸模型的实际命中处留下小块血迹。使用命中盒所属骨骼定位，血迹随模型动作移动。近身持械命中时，实际使用的武器和手臂各增加一层。F 踢击命中给手臂增加一层，使用同一距离配置。空挥保留原有血迹。以上行为是用户指定的自定义效果。
