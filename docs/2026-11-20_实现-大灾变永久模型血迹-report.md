# 大灾变永久模型血迹

近距离枪击命中能出血的灾变僵尸时，血迹同时附着在射手的手臂和实际开火的枪械上。僵尸的受击血迹在其模型可见期间保留。每个实体在第一次沾血时获得固定的贴图变体和位置。后续攻击、时间流逝和切枪都不会重抽。

手臂血迹随玩家在本图存续，重生与同图重玩后仍显示。同一把枪在手持、落地及换人拾取时始终带着自己的血迹。地图卸载、玩家离开和实体销毁是状态回收边界。僵尸池回收再借出时，新僵尸从干净状态开始。关闭模型血迹会隐藏已有血迹，重新开启后按原样显示。

## 管理设置

统一 `gameplay.json` 中的 `features.blood.enabled` 控制模型血迹，默认关闭。M 菜单的「管理员菜单 → 模型血迹」可即时开关并保存。溅射距离 `blood_splash_radius` 默认 128 GoldSrc 单位，设为 0 时只保留僵尸受击血迹。旧版 JSON 中的血迹寿命与上限字段仍能读取，在下次保存时自动移除。

## 运行路径

服务端通过真实弹道和伤害聚合确认命中与开火枪械。血迹状态按实体槽及序列号保存，僵尸逻辑复用命中后的出血分类。现有快照向客户端提供固定的血迹变体，渲染器将六张现有贴图混合进 Studio 模型材质。配置关闭时保持渲染查询停用。启用时每个地图和 GL 上下文准备一次贴图，绘制复用现有提交。

- x86 ReGameDLL 候选 `3998126d…`、ReHLDS、CSOLSupport、Renderer AVX2 和 AMXX 均已完成构建。九组着色器变体通过编译。全树构建回执记录了构建期间的两处客户端文件改动。对应文件未进入服务端编译依赖，另封存并复核了服务端此次链接的 502 项输入。

- 本地测试服的 327 项 HUD 资源预检通过。实战画面、多人可见性和帧时间待验。下次联测前须对实际目标服重跑完整 HUD 资源预检，将 `swds.dll`、`mp.dll`、`CSOLSupport.dll`、`Renderer_AVX2.dll` 和 Studio 着色器配套部署到隔离环境。
