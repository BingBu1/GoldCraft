# 灾变击杀提示与怪物技能

本记录对应穷途末路 `zs_deadend` 中缺少 KILL 提示、僵尸停住和 AI 表现不同的反馈。已通过真实专服黑龙炮攻击复现：带主动技能的角色命中后因技能工厂缺失，目标生命归零但不进入死亡流程；相同路径默认角色能正常双杀。10月30日候选02已部署1/29修复，两角色第11/12轮分别击杀1/2怪、约3秒归池且39活怪移动；客户端画面、其他人物能力与完整AI仍未验收。

## 最新专服差分

第9轮使用默认海豹突击队（class49，无主动技能），真实发放黑龙炮并调用其实际 `PrimaryAttack`，弹药20→19，一次攻击击杀两怪。两怪均deadflag2、solid0、死亡动作121/128，约3秒后归池；其余活怪继续移动，无行为错误或整图拒绝。第10轮只改为阿塔尼斯（class8196，主动技能subtype1），同一攻击使目标hp0但deadflag0、活体动作133、nextthink0。7秒后诊断仍为 `scenario selected active ability factory is not implemented`；其他39个观测活怪继续移动。该轮不能把hp0计作成功死亡。

证据分别为 `build/csol-kill-probe-20261029-09/receipt.json`、`build/csol-kill-probe-20261029-10/receipt.json`。探针使用自有fake client，真实路线破墙与原范围/视线/伤害；仅同步发枪和攻击窗口模拟客户端协议身份，瞄准临时处理fake client没有网络setangle确认的差异。没有改怪物生命、伤害或强制波次。此证据证明该角色路径的站尸原因，不证明所有活怪全停只有同一原因。

第4轮普通M4真实TraceAttack/ApplyMultiDamage死亡、33个后续活怪移动与断线清理已通过，见同名前缀 `-04/receipt.json`。第6轮崩溃由探针 `get_tr2` 浮点成员漏传输出参数造成，转储寄存器/AMX参数/原Fakemeta源码已核，见 `-06/crash-diagnosis.md`；未执行黑龙炮攻击，不列为生产崩溃。首次失败和所有恢复证据保留。

本批新增 `scenario_active_skill.*`，按真实ClassMod选装创建subtype1/29具体初态与伤害消费者；重复相同角色准备不重置冷却，发送原0x24初始化消息。梦瑶type29单独保留source/context门和Stop(key12)内部变化广播，不能用空回调替代。完整主动触发、特殊人物动作及延迟效果仍在补；当前未实现的激活明确报错，不能称技能已完整可用。`csol_scenario_perf players`可显式查看人物、当前选装和实际技能对象，不在每帧打印。

用户新增原版升级框、升级提示、人物技能图标要求已写入领域goal。原图/字体/视频、消息、冷却/激活提示并行接入中，最终HTTP和客户端视觉仍待。

## 验证与复现

KILL 纯状态测试 225 项通过；真实客户端消费者配合明确的引擎/VGUI 边界夹具，在已有和缺失消息 handler 两种环境各 109 项通过。覆盖重复初始化、其他 opcode 转发、畸形包、会话重置、菜单/控制台隐藏、视频重建、退出重新初始化，以及真实 TGA 的透明通道。它们不代替实际 GL 画面和网络投递。

专服诊断使用单独拥有的 fake client，经过真实选队、选人、出生和 RunPlayerMove。首轮仍在出生区，只触发 intro wave50；第二轮实际发M4成功，但未沿北门路径离开出生区，仍是零怪，未注入伤害。结束时实际断线产生整图拒绝：`Scenario player movement upgrade state is unavailable.`。原SDK先注销玩家升级记录，再在卸武器时重算速度，发生于 `has_disconnected` 写入之前；生产规则已补 `WasRemoved` 退役判断，保留活跃玩家的真实缺状态错误。证据在 `build/csol-kill-probe-20261029-02/clear.json`，待新版断线复测。

两次窗口均已停自有专服并恢复临时探针，生产模块哈希、受保护安装和根Git index保持。第二次窗口199.7秒，超原定3分钟约20秒，后续驱动改为120秒硬超时。第三次将按原NAV北门路线触发首波，避免重复空场测试。所有伤害注入证据与真人操作证据分开记录。
