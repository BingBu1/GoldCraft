# 灾变初始资金 7500 与上限 32000

按用户本轮明确要求，灾变账户初始金额设为 7500，实际账户上限设为 32000。已完成源码及独立账户测试；完整 DLL 构建、部署和实服回归尚未完成。普通 CS／ZP 继续使用各自的 `mp_startmoney`、`mp_maxmoney`，灾变不会修改这两个全局 CVAR。

后续部署更新：`build/csol-money-skill-candidate-20261030-02` 已完成六原生模块和两Pawn构建并部署，实际B重新连接得到7500，普通CVAR仍为800／16000，见 `money-after-connect.json`。此证据只覆盖真实初次连接资金；32000实际购买／奖励边界及完整重置仍待。此前阶段的“未部署”描述保留为历史，不再代表当前安装状态。

## 实际接点

[`scenario_money.h`](../native/csol/server/scenario_money.h)提供当前 GameRules 对应的初始金额和上限。判断的是实际灾变规则实例，不是尚未换图生效的请求 CVAR。

| 入口 | 本次行为 | 保留的原生语义 |
|---|---|---|
| ClientPutInServer／进入游戏／观战加入／ReAPI JoinTeam | 读取模式专用初始金额 7500 | 原 `RewardType` 与首次不发送 Money 的规则 |
| CBasePlayer::Reset | 以 `RT_PLAYER_RESET` 传入完整 7500 | AddAccount 内部先归零，再写入新初始余额 |
| 灾变完整重开回合 | 主代理在 `m_bCompleteReset` 分支接入同一 Reset 理由 | 普通阶段推进不重置已赚金额，回调后校验地图与玩家身份 |
| CBasePlayer::AddAccount | 灾变先用 int64 相加，再夹至 0～32000 | ReAPI hook 链、Money 包与 tracked 参数继续有效 |
| ReAPI `rg_add_account(..., AS_SET)` | 先归零后进入同一 AddAccount，仍受 32000 限制 | 不新增私有偏移或额外 Money 包 |
| CheckStartMoney | 灾变直接返回，由模式专用规则提供金额 | 普通 CS 原 CVAR 校正规则保持 |

首次加入不发 Money 的分支也执行灾变上下限校验，不能通过静默写入绕过上限。正负极端整数使用 64 位中间值，不先发生有符号整数溢出。脚本若直接用 `set_member` 写底层 `m_iAccount`，属于绕过账户 API 的原有能力，不在本次接口限额声明内。

SDK 的三处修改位于 `external/ReGameDLL_CS/regamedll/dlls/player.cpp`、`client.cpp` 和 `API/CSPlayer.cpp`，供主代理统一导出 `regamedll-goldcraft.patch`；本子任务未改 Git index 或生成发布补丁。主代理的完整重置接线位于 `native/csol/server/game_rules_gate.cpp`。未修改 `scenario_session.cpp`、`scenario_player_runtime.*`。

## 已执行验证

[`Test-CSOLMoneyMessages.py`](../tools/Test-CSOLMoneyMessages.py)不改写地提取生产 AddAccount 实现和三条奖励调用表达式，以实际 x86 Clang C++20、O3、ThinLTO、AVX2、precise FP 编译。引擎消息出口由夹具接收；随后在 Unicorn 执行 SHA-256 为 `b434b1c09b10b011be6c42e4154955da0c3ca46e95746988ebea1aa316a2a9f2` 的客户端原始 Money 读取指令。它不是游戏内画面或完整 Hook 生命周期测试。

新增覆盖：初次 7500、从 28000 完整重置两次仍为 7500、观战加入、突破原 16000、31900+500 只到 32000、已满不再增加、7500-6000=1500、负数夹零、AS_SET 等效写入 40000→32000、静默同步、无消息加入上限、正负整数极值，以及普通 CS 自定义 1200 初始／40000 上限。原有命中、击杀、破墙、同步与变化额用例继续通过。

本轮命令见 `build/csol-scenario-money-20261030/run-command.json`；环境使用已存在的 `build/csol-scenario-navigation-idle-events-20261026/compiler-environment.json` 中 INCLUDE/LIB/LIBPATH。运行耗时约 2.28 秒，结果为 26 cases／26 messages，`liveGameplay=false`。原始包、构建日志、生成夹具与输入哈希均在 `messages/` 下。
