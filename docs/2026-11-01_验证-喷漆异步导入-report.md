## 复现离线检查

在 Windows、支持 AVX2 的主机上，从仓库根目录运行 PowerShell 7。先按项目工具链要求配置 `GOLDCRAFT_LLVM_ROOT` 或本地工具链配置，安装匹配的 Visual Studio C++ 与 Windows SDK，并按项目锁定版本准备 MetaHookSv/VGUI 头文件。

以下命令只创建新的构建目录，不启动游戏、不部署 DLL：

```powershell
. ./tools/SandboxPaths.ps1
. ./tools/ClangToolchain.ps1
$compiler = Initialize-GoldCraftCompiler
$checkOutput = Join-Path $script:GoldCraftRoot ('build/spray-import-check-' + [guid]::NewGuid().ToString('N'))
New-Item -ItemType Directory -Path $checkOutput | Out-Null
$clang = Join-Path $compiler.Root 'bin/clang-cl.exe'
$flags = @('--target=i686-pc-windows-msvc', '/std:c++20', '/EHsc', '/MT', '/O2', '/clang:-O3', '/clang:-flto=thin', '/clang:-fuse-ld=lld', '/arch:AVX2', '/fp:precise', '/utf-8')
& $clang @flags ./tests/csol-hd-spray/import_job.cpp "/Fo$checkOutput/import_job.obj" "/Fe$checkOutput/import_job.exe" /link /threads:1 /opt:lldltojobs=1 user32.lib
if ($LASTEXITCODE) { throw 'Import worker compilation failed' }
& "$checkOutput/import_job.exe"
if ($LASTEXITCODE) { throw 'Import worker regression failed' }
./tools/Test-CSOLHDSpray.ps1 -Only options -Output (Join-Path $checkOutput 'options')
```

预期任务测试输出 `60 checks passed`，选项页输出 `Production options compiled against matched VGUI SDK; live UI pending`。正式验证另外启用了实际包含文件的 SHA-256 审计；上述命令供独立复现功能检查，不替代发布冻结审计。

## 尚需验证的行为

- 连接专服后保持文件选择窗口打开，继续确认客户端帧、收包/ACK 和服务器可靠队列正常；随后测试取消、慢 GIF 导入、重新打开和退出客户端。
- 页面生命周期应分别实测关闭整个选项窗口与切换选项卡。源码已区分两者：离开当前页取消选图，不重置已编辑候选；返回当前页再接收预览结果。
- 渐进上传每 16 ms 最多一帧，避免 HUD 与 GameUI 双入口重复上传。源码已改为上传期间显示首帧、所有帧就绪后才开始 GIF 时间线；有限播放次数的 GIF 仍需实机观察。
- `ApplySpray → NormalizeSettings → DecodeAnimation(..., false)` 仍同步解码；`false` 只释放解码后的像素，并不跳过解码。设置保存也仍是同步文件写入，本次不宣称喷漆全链路异步。
- 取消不会强行终止正在执行的 WIC/CPU 操作；关闭页面丢弃结果，DLL 结束时等待工作线程返回。普通隐藏窗口验证不等同于完整原生文件选择窗口或第三方图像解码器验证。

测试源码见 [import_job.cpp](../tests/csol-hd-spray/import_job.cpp)，生产任务实现见 [hd_spray_import_job.hpp](../native/csol/client/hd_spray_import_job.hpp)。
