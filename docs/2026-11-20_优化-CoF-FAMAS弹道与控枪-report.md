# CoF FAMAS G2 弹道与控枪

用户要求这把客串步枪更容易控制。宿主 FAMAS 的地面散布乘以 0.75，机瞄继续由子弹函数将散布减半。腰射的横摆冲量取原值的一半，侧倾取四分之一，俯仰保留原值。机瞄时三个视角冲量在腰射基础上再减半。空中沿用原弹道散布。

## 原版行为

原 CoF 服务端和客户端均为 x86 PE32，映像基址均为 `0x10000000`。服务端 `hl.dll` 的 SHA-256 为 `0036b91c01e92ed205513f52563053a55a66a32d257efb5f476b8f1f3dde0e63`。客户端 `client.dll` 的 SHA-256 为 `d2a04641b301804f6f449aa68265042b13adc360925b80033d417ec9f38c9c00`。修改前已核同 IDA 归档索引、31 个区域共 7,130 字节，并在相同原生武器入口记录调整前的射击序列。私有证据见 `analysis/cof-weapons-20261111/famas-20261118/handling/PREEDIT.json`。以下地址为 VA。

| 原版位置 | 实际行为 |
| --- | --- |
| MP `1003C4CF`、`100EF7BC → 1011BB50` | 生成时每发增长量为 0.15。玩家帧按移动、蹲伏和离地状态选取散布，先选向量再处理衰减。 |
| MP `1003BBD0 → 100DFEA0 → 10088CA0` | 射击入口读取当前角度和散布。子弹函数在机瞄时减半，按命令种子生成水平、垂直偏移，再发出射线。首个散布恢复时刻为开火后 0.25 秒，主开火间隔为 0.06 秒，末发另有覆盖。 |
| MP `1003BFC4 → 100F91B0`，client `10052E00 → 100AE9A0`、`100B0834`、`100B2140` | 合作模式发送持枪者视角事件，每发输入为 `(随机整数 −2 至 2, 1, 1)`。客户端累加角速度，随后按帧回正。 |

宿主调整位于 `native/guest/cof/server/famas_weapon.cpp` 的 `FamasWeapon::PrimaryAttack`，在发出本枪的视角事件和调用权威子弹后端时应用。开火时根据已有的姿态和机瞄状态选择乘数。两条弹道路径共享同一个调整后的散布输入。当前沙盒 CS 的事件坐标编码比例为 8192，所用的最小视角冲量 0.125 可以精确表示。

## 弹着与画面对照

原生武器以 100 Hz 接收输入。每种姿态分别测腰射、机瞄、原 CoF 射线和 CS 5.56 材质射线。每版采到 600 发，逐发扣弹、随机种子、发射时刻、原始散布状态与伤害全部相同。单发、三发短点射和连续 30 发分别统计。每组用同一批 256 个起始种子，在距枪口 1024 个游戏单位、垂直于枪口方向的平面上计算到瞄点的距离。

| 条件 | 调整前九成弹着半径 | 调整后九成弹着半径 |
| --- | ---: | ---: |
| 站定腰射，前三发 | 0.00 | 0.00 |
| 走动腰射，前三发 | 24.77 | 18.58 |
| 走动机瞄，前三发 | 12.38 | 9.29 |
| 站定腰射，整匣 | 21.10 | 15.82 |
| 走动腰射，整匣 | 42.60 | 31.95 |
| 走动机瞄，整匣 | 21.30 | 15.97 |
| 空中腰射，整匣 | 77.55 | 77.55 |

对同一串三发输入，原版客户端的后坐分量峰值为横摆 3.54°、侧倾 3.54°。调整后腰射为 1.77°、0.89°，机瞄为 0.89°、0.44°。测量固定鼠标输入，读取原客户端后坐事件和回正阶段输出的角度。
