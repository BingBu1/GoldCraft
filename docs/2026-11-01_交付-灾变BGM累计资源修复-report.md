# 灾变 BGM 与启动资源累计修复

前版 111 项资源补丁漏了 MP3 和部分固定 HUD/特效，正式服继续以 `scenario BGM is missing or empty` 拒绝连接。文件哈希与安装器检查通过，不能证明此前列举的启动资源范围完整。本版补入必需音乐、升级/击杀贴图、音效及精灵，并修正打包器和安装器的 MP3 支持。

累计包 **133 项、17,350,486 原始字节**，完整保留旧 111 项，新增 22 项：3 首准备/普通/冲刺 BGM 与 19 项 HUD、音效和 SPR。仍以已安装的 20261024-CSOL + 20261101 稳定灾变更新为基线；是否装过旧 111 项资源补丁均可直接使用。不会混入新购买/技能 DLL。

交付 ZIP **10,208,894 字节**，SHA-256 `b250c86983f4746e3f0e53f6c469a9336758b828b396d47a77c4d8ad7b4ffc7b`。清单版本 `20261101-Scenario-Resources-v3`，位于 `server-packages/update-20261101-Scenario-Resources-v3`。先运行原 Stop.cmd；解压到服务器目录之外，运行 Update-Server.cmd 选择原 Start.cmd 所在目录，再用原 Start.cmd 启动。

来源复核绑定稳定 mp.dll `a3e32ab1` 对应源与 overlay；55 项源证据身份由主调独立复核。领域工具的 20 项回归及现有生产音乐 reader 已通过；1,429 个声明资源中，1,296 项从两基线 ZIP 的实际字节核对，余 133 项入包。实际 ReHLDS 资源表扣除新本地候选的 51 项后，稳定去重 2,058 项由三包 1,529 项、本次新增 22 项与标准 CS/HL 资源 507 项覆盖；标准资源只在本地做了只读原安装对照，远端基础资源尚未核验。仅针对稳定 zs_deadend，未扩展其他地图或声称每个生产加载器都已执行。

实际 Windows PowerShell 5.1 安装器 **16 项行为检查通过**，使用完整 1,301 项基线校验，未删减为小清单。覆盖计划零写入、损坏 MP3 拒绝、错误基线拒绝、真实文件占用导致中途失败后完整回滚、全部 133 项哈希、基线与配置保持、硬链接旧模型独立替换、重复全跳过、手动恢复，以及从旧补丁升级仅安装 22 项并能恢复旧 111 项状态。

本机应用 22.656 秒，重复 18.573 秒，恢复 2.195 秒，已安装旧补丁后的补充更新 19.887 秒。ZIP 140 条目/133 项 payload 全部解压读字节核 SHA；不含 DLL、EXE、JAR、密钥、PDB 或日志。包内五个稳定版本锚点与独立资源回滚记录保持。

首轮安装成功后，夹具因 Windows Hud/hud 路径大小写不同产生 KeyError；修正为大小写不敏感的快照键后完整通过。首失败与修正记录保留，未调整生产资源或放宽校验。测试临时大基线在逐文件核 SHA 后清理；复用已有冻结资源和交付 ZIP 的已知硬链接，不原地覆盖共享文件，不把逻辑字节统计当作实测物理簇节省。
