# 持久设置菜单截断

设置菜单原来将完整说明放在每一行，并在数值详情标题继续拼接长说明。用户1280×720截图只显示到第4行，翻页/返回项也被截断。

## 修改与依据

核对匹配 AMXX newmenus.cpp：标题经255字节临时缓冲格式化，每项也经255字节临时缓冲，显示阶段另有2048字节缓冲。中文说明不能作为短选项文本反复堆入原生菜单。本次属于用户自定义管理页的宿主显示修复，不冒充原CSOL菜单布局。

[插件](../amxx/scenario/goldcraft_scenario_admin.sma) 为实际48个目录项提供对应的短中文名称，显示当前数值或开关，每页5项，共10页；上下页和返回名称明确。字段位置与key同时匹配，未来未知字段使用有界短key，避免目录调整后误标。

详情页保留字段名、当前值、范围和生效时间，输入按钮不受长说明挤占。完整说明按120字节以内且不拆UTF8字符的片段输出控制台；JSON说明保持完整。中文名称表是编译期常量，按目录位置直接查询，仅在打开菜单时读取字段，没有每帧解析或重复文件读取。插件版本提升为0.6.1。

## 验证

匹配编译器构建零警告。[实际 AMX VM](../tests/csol-custom-admin/pawn.cpp) 执行新插件字节码：根页112项、现有权限/永久设置1214项、完整目录布局143项全部通过，记录输入稳定。布局使用源示例中的实际48个key，并将每项说明放大为499字节中文；十页的最长菜单为354字节，包含导航/退出文本，低于本任务采用的保守511字节兼容预算。数值详情标题也完整；实际分段输出重组后与原说明逐字节相同。

本地回执 build/csol-settings-compact-vm-20261113-02/receipt.json；第一次布局检查把普通“说明”二字误当作长说明泄入标题，失败保留，仅纠正测试的匹配条件。验证预算采用匹配AMXX颜色/页码格式，菜单API为受控边界，不将它描述为最终像素验收。
