# 服务端权威视觉效果

夜视、失明和黑暗使用独立的视觉状态通道，覆盖 MC 形态和原生 CS 形态。状态来自唯一的 MC 服务端效果所有者；HUD 图标和客户端声明不作为依据。

## 状态及失效

协议30新增可选能力16384和消息90。固定48字节包含world/revision、slot/serial/spawn/life以及四个有限的0–1系数：夜视、失明、黑暗渐变和黑暗脉冲。脉冲不得超过渐变系数的0.45倍。

ReGameDLL检查协商、世界、连接、出生、生命和存活状态，并在可重入回调后再次核对身份。只向已就绪且声明`_gc_vision=1`的对应真人客户端转发`GCVision`。客户端匹配自身身份、拒绝旧revision，350ms无更新即归零。换图、重连、形态/生命变化清理；旧客户端逐级降级，不收到未知消息。

Renderer使用独立可选接口`MetaRendererSceneVision_API_001`，仅接受已注册的场景所有者。自身另设350ms引擎时间租约，时间倒退、卸载/换图清理，阴影视图不应用。状态并入现有SceneUBO上传，不增加每帧GL查询或纹理上传。

## 画面计算

- 夜视在照明与材质颜色相乘前归一化，完全黑色的宿主光照使用0.03最低照明；保留材质颜色、原版末200tick闪烁和无限时长语义。
- 失明按5格视距和最后20tick衰减计算；地形起点为视距25%，天空使用80%终点。它优先于黑暗。
- 黑暗读取实际效果实例`getFadeFactor`，使用15格视距、75%雾起点和基于实体年龄的余弦脉冲。不会重新启动独立计时器。
- 延迟渲染在最终照明合成时处理一次；前向渲染在材质相乘前处理。Specular附件原本保留的B通道标识已照明/发光材质，避免水反射、精灵、全亮/加法材质重复提亮。HUD、原始后处理遮罩及阴影输出保持各自语义。

## 验证与边界

当前证据位于`build/status-vision-20261016`。完整Java测试308项、生产JAR及生产发布器446项检查通过。测试覆盖时长、真实fade输入、脉冲、叠加/移除、能力、死亡/身份/世界重置；Minecraft API使用观察适配器。

隐藏窗口的真实OpenGL测试执行实际Renderer接口与完整延迟合成shader，191项检查覆盖租约、着色器编译、材质颜色、发光跳过、天空/地形雾、零状态恢复。生产客户端、ReGameDLL、Renderer及JAR构建通过；原生84项和Renderer25项回归全过。它证明GPU计算，不代表实机画面、性能或多人验收。需同时更新Renderer、GoldCraft与配套的7个shader文件，候选尚未部署。

尚需两种形态在暗室、天空、水面、发光方块与不同材质上真人验收，覆盖到期、喝奶、死亡、重连和换图。潮涌水下视觉、反胃、发光轮廓和剩余玩家/死亡回调仍单独开放，不能据此关闭全部39种效果的目标。
