# 原生 CS 移动状态适配

Minecraft 1.21.1 / NeoForge 21.1.256 的唯一服务端效果所有者发布移动状态，原生 CS 形态接入匹配 ReGameDLL 的实际移动函数；MC 形态继续使用 Minecraft 控制。移动适配已随本地联合更新部署；新增[摔落属性](NATIVE_FALL.md)候选已构建并通过自动检查、未部署，完整真人移动验收仍待。

## 权威与预测

可选能力 `4096`、消息 `88`，协议版本仍为 30。负载严格为 44 字节：world/revision 为 u64，slot/serial/spawn/life/flags 为 u32，跳跃增量和飘浮目标为 float。接收端检查长度、范围、有限值、身份和递增版本；350ms 租约、换图、换连接、重生、死亡和形态切换限制旧状态。旧端协商按原凭据逐级回退，未协商时不发送该消息。

服务端 `GCMotion` 只发送给声明 `_gc_motion=1` 的真实客户端。客户端匹配 CS client 的 SHA256、CRC64 和已核验函数目录，通过 MetaHook `ResolveGameSymbol` 挂接 categorize/jump/water。无法安装时不声明预测能力；普通旧客户端没有本模块预测，不能将其移动平滑性算作已验证。

## 已接入行为

- 缓降：下降时以分数 20Hz 速度规律调整两个原生半重力步骤；上升及真实跳跃保留原生重力。
- 飘浮：同样使用分数 tick 规律；上升时取消原生两单位向下贴地，保留实际移动 hull、天花板碰撞与移动类型限制。
- 跳跃提升：读取 MC 跳跃增量，仅在实际原生地面跳跃成功后增加速度；ReAPI 取消跳跃、中途跳跃保持原语义。
- 海豚的恩惠：仅水中暂时调整拖曳、速度上限和输入加速度，离开调用即恢复；不改变岩浆。

临时 movevars 不保存在玩家 user 字段；同一移动对象重入时使用原生重力，并在返回后恢复外层临时状态。环境免摔伤由[环境防护模块](NATIVE_ENVIRONMENT.md)执行。

## 验证与缺口

生产 Clang x86 客户端/ReGameDLL 与 NeoForge JAR 已编译；5 项原生 CTest、299 项 Java 测试通过，零失败/跳过。原生移动夹具从匹配源码抽取重力、分类、跳跃和水移动，53 项检查覆盖普通重力负对照、升降、天花板、ReAPI 取消、死亡/观战/水体和重入恢复；实际派发器另测身份、租约和预测投递。Java 发布器通过 75 项适配器检查，真实 TCP 协商用例验证消息 88 已进入计数。首次夹具栈空间及异常报告问题、Java 消息计数长度错误已修，失败记录保留。

ReGameDLL 累积补丁在固定上游版本重建后与当前修改文件逐项一致。客户端目录生成检查 32 个匹配符号；这些属于源码/自动验证，不是游戏内 ABI 和移动手感验收。

跳跃提升的摔落距离减免已接入独立属性通道和实际落地消费者，自动检查通过但未部署。任意重力/跳跃/no-drag 属性和完整原版水中 travel 语义仍缺。所有移动效果仍需双形态浅深水、低帧率预测、上下坡/梯子/门、换图重连和重生真人测试；视觉、玩家专属、死亡回调等其余效果见[39 项覆盖审计](STATUS_EFFECT_COVERAGE.md)。

本地证据在 `build/status-motion-work`：`native-tests06.xml`、`server-build06.log`、`java-build05.log`、`publisher/result.json`、`patch-replay.json`；旧 `analysis` 证据已按要求删除，不再依赖它们。
