# CSOL 单附属模型系列与动作衔接

已验证五组新武器的主体和附属模型组合：`v_linkattacksg`、`v_roboarm`、`v_roboarm3`、`v_sfboomerang`、`v_sfboomerang6`。默认自动寻找配套文件，按同名骨骼合并，独立播放附属动作。此检查点尚不代表完整 CSO 游戏行为一致。

## 使用

打开主体 MDL，在“CSOL 预览 → 组合模型”选择附属动作。展开／切换结束后默认按客户端时长衔接持续动作，收回后进入待机。关闭自动衔接可以逐帧检查原序列；暂停、定位、从头播放与配置保存均可用。

机械臂包含两个独立根骨骼，必须分别跟随主体。飞镖没有同名 JSON 时也能组合，其附属皮肤跟随主体。联动霰弹枪的展开状态切换附属皮肤。不能用主体动作编号代替附属动作编号。

打开附属文件时，“打开完整武器”可跳到主体。导出从任一成员收集配对模型及关联资源，保留 common 下原目录关系。源 MDL、撤销历史不受预览操作影响。

## 结论

**F-01：显式登记配套关系，不能泛化为所有 `_parts` 文件。** E-01 的联动霰弹枪初始化 `0x021A09C0`、机械臂初始化 `0x02204EA0`、飞镖普通/6 版本 getter `0x0210E1F0`／`0x0210E670` 给出独立模型。`v_sfboomerang1` 也有客户端登记，但当前文件树缺少对应 MDL；实现不造替代文件、不把其他版本改名套用。配对还检查主体及附属的完整动作表。

**F-02：附属动作由武器状态和独立时钟驱动。** E-01 的联动霰弹枪 `0x021A0A20`、机械臂 `0x02205000`、飞镖 `0x0211B210`／`0x0211A400` 决定转换。联动霰弹枪的 0.7 是 double，严格超过截止时间才切换；其他两组使用原 float 值，达到截止时间切换。E-03 验证截止前后、精确边界、剩余时间、手动保持、播放及暂停。

| 系列 | 展开／切换 | 收回 | 到期动作 |
|---|---:|---:|---|
| linkattacksg | 0.7 秒 | 0.7 秒 | 1→2、3→0 |
| roboarm / roboarm3 | float 0.33 秒 | float 0.67 秒 | 1→2、3→0 |
| sfboomerang / sfboomerang6 | float 0.7 秒 | float 0.53 秒 | 1→2、3→0 |

**F-03：每个合并锚点都影响后代骨骼。** E-01 的客户端 StudioMergeBones `0x02ACCA80` 与实际模型共同支持同名映射；机械臂的根骨骼顺序与主体不同。E-03 以独立坐标变换 `主体锚点 × 附属锚点逆矩阵 × 原附属骨骼` 检验所有动作、普通和镜像缩放。五组最大矩阵误差不超过 0.000366211。禁用骨骼合并的实际渲染负对照与正确组合不同。

## 调用路径

P-01：打开主体 → 显式客户端系列登记及动作表校验（E-01/F-01）→ 读取配套模型与 JSON → 按名字构建全部根和共享骨骼映射（E-01/F-03）→ 独立时间推进及到期衔接（E-01、E-03/F-02）→ 使用合并骨骼和实际皮肤绘制（E-03）→ 按相同资源优先级导出并离线重开（E-04）。
