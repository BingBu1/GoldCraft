# 原生玩家的状态环境防护

Minecraft 服务端把抗火、水下呼吸／潮涌、缓降／飘浮的环境防护发送给 ReGameDLL。独立 `NativeEnvironment` 和 `status_environment` 模块负责此通路，效果表仍只有一个持有者和计时器。

协议30增加可选能力2048与36字节消息87，不改变旧属性消息77。快照包含world、单调revision、slot、连接serial、spawn、形态life和三位防护标志。原生只接受已认证MC服务端；消息严格检查长度、身份和标志，租约350ms。未协商、到期、死亡、换连接/生命/世界或时钟回退均不能留下防护。旧原生服务端拒绝新能力时，MC按原凭据重连逐级退回旧能力集，不向旧服发送新消息。

原生 `TakeDamage` 在护甲/生命结算前检查免疫，已有ReAPI外层回调保留。火焰与缓慢燃烧对应抗火；溺水对应水下呼吸或潮涌；坠落对应缓降或飘浮。带多种原因的伤害只有每种原因都受保护时才整体免疫，因此抗火不会吞掉 `BURN | BLAST` 的爆炸。MC已结算的伤害仍保持原始伤害标签和回调结果，不能被此通路再次免疫。

实际 `CBasePlayer::WaterMove` 保持真实waterlevel，防护有效时补满空气并复位溺水增伤，既不伪造出水，也不记录从未发生的溺水伤害。此前实际溺水的恢复债务保留。抗火不免疫酸液；失去防护后按原生空气时间与伤害继续执行。坠落防护同时清理原生落地计数。

此模块只完成环境防护，**尚未实现缓降的下降重力、飘浮移动、海豚水阻、跳跃提升或视觉效果**；全部39种效果的剩余边界见[覆盖审计](STATUS_EFFECT_COVERAGE.md)。不能据此把缓降/飘浮完整效果标为已修复。

验证使用实际桥接消费者和匹配ReGameDLL的WaterMove函数体，替代引擎声音/随机/伤害接收器：47项防护、混合伤害、真实水位/空气债务、身份/租约/回调重入及协议拒绝检查通过。生产Java发布器169项观察适配器检查通过；四项真实TCP用例覆盖新能力、旧服回退、过期generation和图形客户端拒绝，既有TNT/玩法协商用例保留。生产构建与完整测试记录位于本地 `analysis/status-environment-20261016`。未部署或执行真人玩法验收。
