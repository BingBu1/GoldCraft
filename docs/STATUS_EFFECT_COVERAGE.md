# Minecraft 1.21.1 状态效果覆盖审计

用户要求覆盖全部原版效果。以下清单对照固定的 Minecraft 1.21.1 / NeoForge 21.1.256 注册和执行源码，共 39 种。它是未完成项的审计边界，不表示下表效果已经全部实现或实测。

已有结构：MC 形态由真实服务端玩家持有效果；原生 CS 形态由唯一 `NativePlayerHitboxEntity` 效果表执行计时和伤害回调，通过原生权威结算生命。形态交接转移原实例，保留隐藏效果和吸收池；客户端 HUD 只镜像，不再执行服务端效果。现有跨端属性包含速度、抗性、吸收和盾牌；独立可选消息87补入[环境防护](NATIVE_ENVIRONMENT.md)，消息88接入[移动适配](NATIVE_MOTION.md)。生产编译/自动回归通过，均未作为完整39效果或真人验收。
