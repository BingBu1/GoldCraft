## 实际实现

[控制器](../native/csol/server/scenario/core/human_kick.cpp) 在服务器验证生命、世界、当前武器和体力，允许武器忙碌时开始。一个正在执行的动作保持独占，结束后不再附加旧1.1秒等待。原脚模和真实第三人称序列完成标志仍决定结束，不用猜测计时器。

[通用恢复接口](../native/csol/scenario/custom/action_resume.hpp) 使用服务器内的单调动作代次，不发送指针、不拷贝库存。普通 CS 武器只恢复演示字段和扣除已流逝时间后的原玩家计时，不调用 Deploy；已经换枪或外部回调替换的计时器保留。恢复过程阻止同步重入。

[Glock](../native/guest/cof/server/glock_weapon.cpp) 保留当前动作、绝对截止时间、弹匣和备弹。原独立 Think 可以按原期限推进，脚模占用期间延后枪械的视模/瞄准/body呈现，不能覆盖踢击锁。结束时使用当前弹药提交到期换弹一次；观察者失败后保留已经提交的账，只重试显示。未到期换弹继续原截止时间。换枪、死亡、重生和武器退役取消旧代次，不恢复旧枪。现有 guest 身份及库存恢复声明作为当前 Glock 类的显式依赖保留；本次踢击没有调用库存回滚。

[体力消费者](../native/csol/server/custom/action_stamina.cpp) 使用固定33槽，绑定真实世界、玩家登记、生命及出生代次；真实接受后按动作 token 单次扣费。原普通 CoF 上限100、恢复1/蹲姿2、严格0.25秒周期来自先前匹配原证；踢击10、黄昏容量1.5和恢复1.25是已单列的自定义默认值。时间功能尚未接通时采用正常有限体力，不把配置开关伪造成正午。正午无限需要真实阶段拥有者显式发布；世界昼夜、奔跑/起跳事件和阶段图标仍待接入。

体力数值遵守已声明的下地图生效范围：当前地图固定快照，永久保存不能在当前生命或复活时偷偷改变成本；即时踢击开关独立生效。设置仍来自同一个 gameplay.json，没有逐武器 CVAR。热路径不解析 JSON 或读盘；真实性能尚未采样，不根据组件运行时间报告 FPS 收益。
