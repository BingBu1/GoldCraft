## 原版证据边界

原版 x86 hw.dll SHA-256 为 `c7bddfda93c2e0877ea126a15a318b83cce74c59bb95e38a7301b08033ac7783`，映像基址 `0x37100000`；本轮完整重算一致。已有 IDA `preserve-cache-0` 的 12 段、3,361 字节与对应 PE 地址逐字节相等。没有新建 IDA 会话，不将本轮资源解析称为新增 IDA 证据。

- `0x378B08EC–0x378B090D` 选择非像素前缀并分配，`0x378B0D46–0x378B0D4D` 复制同一长度。
- `0x3787FCDC/0x3787FCEA` 起计算原前缀加原描述符长度及全部 SEQ 文件长度，`0x3787FDD6` 写新 length；`0x3787FE33/0x3787FE3D/0x3787FE4D/0x3787FE6D` 是临时清 textureindex、合并、加载和恢复路径。代入本例为 6,019,932 字节；当前多 1,661,920 字节，等于重复动画 1,662,024 减 13 个 SEQ 的八字节头。
- 原独立固定 cache arena 经 `0x378A01AC → 0x3798C5A0` 初始化；`0x3798AE70` 容量不足仍淘汰 LRU。不能据此无限扩容、逐模型分配永久堆或取消跨图清理。

上述证据支持消除本地打包冗余的方向。下面复用旧区间是保持语义的本地实现候选，不声称原版采用相同算法。143 个角色的跨时间观测工作集仍约 1.044 GiB；减少单角色冗余并不证明全部模型能放进 256 MiB，也不证明解决实际换图耗时。原客户端角色预加载/按需策略仍须另行取证。

## 最小候选：复用已经不再引用的原动画与描述符区

逐条原槽等长覆盖不可直接使用：本例 174 条的真实 RLE 尾部余量分别为 125 条零字节、49 条两字节；现安全合同要求四字节末端可读 padding，174 条均装不下。不得借下一轨道或描述符的字节来放宽现有不重叠安全范围。

更小的候选是从结构证明可复用的连续 arena，而不是重定位整个模型。本例原动画与旧描述符的联合区间 `[5460,1698108)` 有 1,692,648 字节；当前算法生成的各 native track 加四字节 padding、再按四字节对齐，总计 1,662,720 字节，可容纳且剩余 29,928 字节。最终描述符仍另行追加并更新 seqindex，其他几何和事件等绝对偏移保持原值。候选可避免追加这份 native 动画；这是静态容量计算，不是已经生成的新文件大小。

资格判定必须采用以下完整边界，失败仅回到现有打包路径，不能拒绝原本支持的模型或省略动画：

1. 仅处理已解码、边界和整数运算均验证的 v10 模型。按实际范围推导 arena，不按角色名、固定起止偏移或“最早动画到纹理前”猜测。旧描述符只有在已完整复制到独立存储、最终描述符发布后才算不再引用。
2. 全部原描述符、动画源字节、骨尺度、事件和 pivot 均从不可变输入读取。先验证、量化并保存独立结果，再写 out；后续转换不能读到已经重写的 out。容量预检在第一次覆盖之前完成。
3. 枚举全部 native track 的 channel tables、RLE run headers 和 sample ranges。原轨道可跨 sequence 共享或重叠，不能把“动画起点互不相同”当作独占证明。输出为每条轨道独立副本；每条仍执行现有共享字节量化一致性和 header/sample 角色校验。如果尝试保留输出共享，必须额外证明所有共享写入的目标值、单位和角色一致，不能复用当前仅单 track 的 written 检查作跨 track 证明。
4. 每条输出保持现有 used 范围、量化结果、四字节 terminal padding 和对齐。所有输出区间独立、不重叠，完整容纳于 arena；多余空间不得被当作可供安全检查越界读取的理由。容量不足即不启用复用。
5. 非动画引用闭包不得与 arena 相交：header/bones/controllers/hitboxes/attachments、最终仍使用的 events/pivots、seqgroups、skin/texture records、bodyparts、nested models、mesh records、vertices/normals 与骨索引、完整三角命令流及 transitions。所有计数乘法、偏移和终止命令须受真实输入长度约束；不能只检查顶层结构起点。
6. 保留 sequence 的 motiontype/motionbone/linearmovement、frames/blends、activity、事件、pivot、序号和 group 语义。非零 automoveposindex/automoveangleindex、sound 字段、deformation group 或尚不明的扩展字段必须先补消费者/长度证据，否则该模型不具备复用资格。禁止把未知字段清零后通过资格。
7. 当前仅支持描述符 seqgroup=0 的既有条件不变。seqgroup0.data 影响动画相对基址，不能默认为零；非零时须证实消费者和实际引用范围，否则不启用复用。其他 group 的 cache/data 字段不得盲当文件绝对偏移重写。
8. 事件和 pivot 可以位于任意已验证范围或与其他引用共享；只有确认其仍需的字节不在覆盖区时才可复用。mesh 的 normindex 等字段也须按对应消费者语义解释，不能笼统将所有整数称为指针。
9. 最终安全记录仍按序列编号与描述符一一对应，同时按 animation offset 单调排列且不重叠，以满足 ReadSequenceSafety 和二分查找；native 复用区必须先于外置 SEQ 动画区。safety records、footer 和最终 descriptors 继续位于纹理边界之前，UnsupportedTrack 的保留/拒采样语义不变。
10. 完成全部内容后才更新最终 header、texturedataindex、纹理 image offsets 和发布 owner generation。更新 retained bytes 与 CompleteLoad 的匹配分配/复制要求不变，不能暴露部分覆写的模型或绕过安全检查。

本例已检查 63 个非动画范围，均不交叉原动画区；automove、sound、deformation groups 为零，seqgroup0.data 为零。这只证明本例，不代表一般非零字段已有完整解释。原描述符区的可复用性仍必须由通用资格检查闭合，不能仅凭模型已正常显示推断。
