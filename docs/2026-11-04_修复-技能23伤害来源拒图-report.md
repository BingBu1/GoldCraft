# 修复：人物技能23禁用并拒绝地图（scenario source entity has no verified source adapter）

用户报告（2026-11-04）：
```
[CSOL] Character skill 23 disabled: scenario source entity has no verified source adapter
ERROR:  CSOL map rejected: scenario source entity has no verified source adapter. Fix the configuration and reload the map.
```
GPT 在 `build/csol-skill7-20261104/live-readonly-02/server-after-effect03.log` 的只读调试中也读到了同一 `skillFailure`，本报告完成修复，交主协调核收构建/部署/实机。

## 原因

- 技能子类型23（目录 `catalog.cpp` 行带 `DamageCallback::StopCloaking11`）是隐身类：隐身者造成伤害时，按原版虚函数 v138（虚表字节偏移 0x138、第78槽）读取伤害来源实体的武器ID，决定是否解除隐身；击杀与命中组件同样使用该读取。
- 移植层 `CCSOLScenarioPlayerRuntime::ReadEntitySource` 对“非玩家/怪物、非已验证武器、非已登记投射物”的实体一律报错，错误沿技能/死亡事务上报并拒绝地图。
- 原版 MP（`39f962f3…`，只读 PE + RTTI 扫描，未打开 IDB）：`CBaseEntity` 第78槽 `10608050` 为 `xor eax,eax; ret`。全部 1836 个实体类中，原生 CS 类只有武器（`CBasePlayerItem/Weapon` 返回 `m_iId`、`CKnife` 返回 29）与 `CGrenade`/`CHEGrenade`/`CAirtank`/`CMortar`（`10622D80` 返回 4）覆盖该槽；`CBreakable`、`CEnvExplosion`、`CTriggerHurt`、门、列车、`func_tank`、玩家、怪物等均返回 0。证据 `build/source-adapter-20261104/slot78.json`（脚本 `slot_overrides.py`、`vtable_slot.py`）。
- 因此玩家打爆可破坏物/爆炸物、或其他地图实体以玩家为攻击者伤害怪物时，原版得到来源 0，移植层却报错；另外移植层只认已登记的 HE 手雷，原版对任何 `CGrenade` 都返回 4。

## 修复

`native/csol/server/scenario_player_runtime.cpp` 的 `ReadEntitySource`：
- 未验证的武器实现仍报原错误（保留移植层对武器击杀回调的安全设计，已有测试断言）。
- 已登记投射物优先；否则任何 `CGrenade`（含 airtank/mortar）返回 `WEAPON_HEGRENADE`(4)。
- 其余实体按原版默认返回 0，成功，不再报错。所有调用方对 0 均按“非武器来源”处理（2264/2844/2963/3177 行及 `SourceWeapon`）。
