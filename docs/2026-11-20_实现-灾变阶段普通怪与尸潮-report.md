# 大灾变阶段普通怪与永夜尸潮

## 游戏行为

- 黄昏增加普通怪基础移速，可配置每秒回血。永夜分别配置基础伤害、移速和回血。加成对当前地图的存活普通怪生效。回血分阶段记录采样时间，按实际经过时间计算，受最大生命值和可受伤状态约束。
- 阶段普通怪占用上限取当前阶段的基础值加每位已加入战斗队伍的真人增量，最多使用实体池的 39 个普通怪位。死亡后仍在队伍里等待复活的玩家继续计入。Bot、观战、HLTV、等待选人和未完成连接的客户端不计入。
- 尸潮依赖已开启的阶段怪量。永夜第一次处理重复刷怪行时开始计时，按配置间隔抽样。成功后在持续窗口内提高普通怪上限，增量默认 8，也受 39 个普通怪位限制。间隔从上次抽样失败或上次尸潮结束时开始，配置生效后的首个符合条件的刷怪批次处理到期事件。
- 重复普通怪行继续消耗原地图点位配额。达到自定义上限时跳过该次普通刷怪，点位配额保留。限额下降后，原有怪物照常活动和死亡，后续刷怪按新上限执行。一次性刷怪和事件行、BOSS 和精英仍走原调度。
- 三项阶段基础上限、每人增量、尸潮间隔、概率和持续时间由管理员填写。能从 M 菜单保存到同一份 `gameplay.json`，控制台 CVAR 可在当前图临时覆盖。黄昏强化、永夜强化、怪量和尸潮默认关闭。普通关卡推进沿用本局尸潮计时，挑战结束、关闭时间系统和同图重玩清除计时。

## 接入位置

这些数值是用户指定的 GoldCraft 自定义玩法。怪物分类沿用现有普通怪行为条件，原大灾变刷怪行时钟、点位配额和怪物池的原始行为保留。

- [玩法设置](../native/csol/server/custom/gameplay_settings.cpp)读取同一份持久配置和即时 CVAR。非法 CVAR 值按持久配置回退。
- [灾变规则](../native/csol/server/scenario/core/game_rules_gate.cpp)发布当前战斗阶段。[刷怪调度](../native/csol/server/scenario/core/scenario_gameplay.cpp)在每个实际刷怪批次最多计算一次上限并推进尸潮时钟。
- [怪物工厂](../native/csol/server/scenario/monsters/scenario_monster_factory.cpp)在重复普通怪受上限节流时保留原点位配额。普通怪移速和伤害仍经过其既有动作与伤害服务，固定速度技能、梯子和已有速度效果优先。

## 验证

- 当前工作区完整 x86 服务端成功链接，封存了 500 个 SDK 复用的链接输入。阶段刷怪与强化六组实际 GameRules 回归通过，共 134 项行为和 9,643 项 SDK 检查。
- 同一图验证了真人加入与转观战影响后续刷怪、限流不消耗点位配额、尸潮结束保留存活怪物、跨关继续计时及同图重玩重新抽样。重玩用例经实际重玩服务和规则帧进入正午，手动补齐测试演员的玩家档案，因为夹具跳过了原生出生。
- 配置解析通过 977 项。管理员设置、持久保存与进程重读，以及 Pawn 菜单分组回归通过。实测回执目录为 `build/custom-monster-buffs-20261120`。
- 仍需本地专服多人实战和主线程性能采样。该构建未部署到测试服或正式服。
