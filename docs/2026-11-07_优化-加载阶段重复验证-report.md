# 加载阶段重复验证诊断

本轮先测量再选择优化，不改变CSOL玩法。已部署引擎8b20a7ea的三轮worldspawn占完整changelevel约69%。实际开源宿主调用链为Mod_LoadModel→GoldCraftDecodeStudio→GoldCraftLoadStudioOwned；对已带本地安全metadata的模型，decode入口、PreparedSequenceModel::Read和PlanStudioStorage各调用ReadSequenceSafety全轨验证。普通未标记模型只在前两次执行固定头/footer检查，不能误算成三遍全轨扫描。

诊断实施前合同：在实体准备和模型依赖广告两个同步阶段，各累加文件读取、CRC、完整decode、decode入口safety、owner准备、存储计划、缓存分配/复制与owner提交的计数/秒数。默认GOLDCRAFT_MAP_LOAD_TIMING关闭，不调用时钟、不逐模型写日志；阶段结束只输出聚合。decode包括内部safety，计时不可相加。嵌套阶段和非C++退栈用新的generation丢弃旧诊断scope，不保存栈地址或改变加载失败处理。只做正常完成路径的性能证据，不把异常中断记录为成功加载。

依据是当前匹配ReHLDS及项目宿主源码；既有原版模型缓存/消费者证据见2026-11-07专服代理模型与缓存报告。本诊断不是原CSOL源码还原，也不据文件名、日志间隔或截图跳过验证。当前阶段尚未优化或部署。

诊断边界补充：嵌套Phase有意使外层无效，仅报告最新正常完成阶段；不存在栈指针恢复。Phase遇C++异常展开不发布。Scope的calls是完成阶段内的尝试数，不是成功模型数；父Decode包含DecodeSafety和SEQ读取/转换，不相加。file_read只统计主MDL读取，SEQ文件读取仍含于decode。Host_Error非C++退栈遗留的数值在下个Phase入口清零，绝不作为下轮结果。

实物纠正：当前专服150个角色alias的磁盘MDL均无SequenceSafety footer，目录也无配套SEQ。故不能将上述“三遍完整验证”的条件路径称为现服人物的实际负载；该批资源前两次是Absent检查，完整动画扫描位于PlanStudioStorage。先前口头热点判断撤回，聚合计时及真实buffer基准决定下一步，不为基准人为制造tagged数据。
