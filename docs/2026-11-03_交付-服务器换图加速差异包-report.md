# 服务器换图加速差异包

本次补丁只替换服务器的 `cs/swds.dll` 和 `cs/filesystem_stdio.dll`，接入已验证的资源版本缓存，保留 FastDL 修复。运行载荷合计 2,542,080 字节，没有新增资源、配置、GameDLL、客户端 DLL 或 PDB。既有灾变模式和原启动入口保持。

默认目标为 `E:\cs_MineCraft\GoldCraft-Servers`。服主先运行原 `Stop.cmd`，在服务器目录以外解压补丁，运行 `Update-Server.cmd`，成功后用原 `Start.cmd` 启动。其他位置通过 `-TargetDirectory` 指定；`-Plan` 只读预览，`Restore-Server.cmd` 从独立备份恢复。本包是引擎差异更新，不承诺补齐尚未应用的玩法、武器或资源包。
