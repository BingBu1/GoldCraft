# 冰桑启动器图标与公网下载恢复

用户截图中的 `CSOLSupport.dll` 校验失败已在真实公网复现。签名清单与本地发布一致，两个完整下载均返回 3,036,672 字节，但尾部内容不同，SHA-256 分别为 `4c7e7163…`、`3fe359f9…`，都不是签名要求的 `ace18e1c…`。因此旧启动器正确拒绝安装。

## 修复与交付

新版本 `2026.11.01.5` 在整文件长度或内容校验失败后，自动以 512 KiB 的范围请求重试一次。每段必须返回 HTTP 206、精确的 Content-Range 起止位置和文件总长度；下载完成后仍按原签名清单校验整个 DLL 的 SHA-256。失败不会替换游戏文件或更新版本记录。该策略覆盖全部允许更新的核心 DLL，保留普通完整下载的单请求路径。

新 [CoreDownload.cs](../tools/client-launcher/CoreDownload.cs) 独立处理下载恢复，更新器继续负责签名验证、白名单和事务安装。没有忽略错误、降低哈希要求、接受另一份 DLL 或暴露下载地址。

单 EXE 加入原创冰蓝方块图标，包含 16、20、24、32、40、48、64、128、256 九个尺寸。Windows 可执行文件资源与窗体 Icon 均使用同一个内嵌 ICO，玩家无需另外放置图标文件。图标由 [icon.py](../tools/client-launcher/icon.py) 使用 Pillow 绘制，构建自动生成；公开仓库只包含生成源码。

交付文件：`dist/冰桑启动器/冰桑启动器.exe`，75,138,921 字节，SHA-256：

```text
fd2a546e511ab7ecf740d608caea3ce39a638ced24e16cbb1d763e1a20e2adae
```

独立 ICO 同时放在 `dist/冰桑启动器/冰桑启动器.ico`，便于用户自定义快捷方式。更新 EXE 使用独立临时文件原子替换，旧交付保留独立备份；没有改动原 Steam 安装。
