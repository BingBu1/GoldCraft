# 大灾变三类武器盲盒

普通玩家在 M → 购买系统中可选择 CoF、CS 1.6 或 CSOL 武器盲盒。新增玩法默认关闭。管理员可在同一菜单打开功能并保存三档价格。默认价格为 3000、6000、9000 CS 金钱，必须严格递增。调价后，仍打开旧菜单的玩家需重新打开购买系统确认新价格。

`addons/goldcraft/config/gameplay.json` 的 `features.blind_box.pools` 定义三类奖池。奖品默认等权，权重 0 停用。服务端先按当前地图可用性、武器分类及玩家已有库存筛选，再按剩余权重抽取。发放使用正常武器交付路径。余额不足、非购买区和空奖池均拒绝交易，扣款后发放失败会补回该笔扣款。默认开关、价格、等权和空奖池行为是 GoldCraft 自定义规则。

配置解析时校验结构、重复武器、权重和价格。读取或保存配置时准备奖池，购买时最多遍历对应的 64 个候选，无逐帧读取或分配。运行中的旧配置可读取旧版无奖池字段的 `gameplay.json`。见 [配置样例](../native/csol/config/gameplay.example.json)、[服务端购买](../native/csol/server/buy_menu.cpp)和 [M 菜单](../amxx/scenario/goldcraft_scenario_admin.sma)。
