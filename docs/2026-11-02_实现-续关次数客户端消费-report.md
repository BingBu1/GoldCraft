## 已写入的行为

`scenario_respawn_ui.hpp/.cpp` 消费严格 10 字节消息：27、29、remaining signed LONG、initial signed LONG。两个值均按 little-endian 32 位有符号数读取，不经 SHORT 截断。支持原消费者的第二参数语义：initial=-2 清空次数文字，initial=-1 使用原资源 token，其余显示 remaining/initial；低于已知 -2 sentinel 的数据、截断和尾随字节拒绝且不覆盖既有状态。次数更新不触发续关声音、公告或使用物品请求。

预算随普通回合消息、ResetHUD 与视频重建保留；InitHUD、会话切换和完整关闭清除。客户端只显示服务端快照，不预测扣减、补充或重新选择次数。收到数字快照后即保存，随后读取本地化时重新格式化。

`scenario_retry_scoreboard.hpp` 通过匹配 SDK 的 `IPanel` / `IVGui` 公共接口查找实际 `ClientScoreBoard`，使用 HPanel 解析当前 VPANEL，检查它仍归属当前 embedded root 且祖先均可见。面板删除、地址复用、根面板代次变化及视频/会话重置均不保留旧裸指针。查找最多 1024 节点、固定 256 项栈，失败后每秒重试；已找到的面板不逐帧遍历整棵树。未查询 TAB 键或修改任何输入绑定。

显示实现沿用既有 BaseUI post-paint 通道，默认附在宿主记分板下方，屏幕底部空间不足时放在其上方；两边都没有空间时不覆盖玩家列表。字体采用已核实存在的宿主 `Default` / `DefaultSmall`。文字在消息或本地化变更时格式化，绘制不创建字符串；面板查找不逐帧分配容器。

### 与 SDK 读取规则的对照

匹配的 `external/MetaHookSv-20261007/MetaHook/include/SourceSDK/tier1/KeyValues.cpp` 在 316 行的 `ReadToken` 调用 `EatWhiteSpace` / `EatCPPComment`；1799/1820 行的递归读取连续获取 key/value。`utlbuffer.cpp:380` 跨行吞空白。这是 token 流，不是“一物理行一词条”；无引号 token 遇 `"`、括号等停止，也与本项目旧 tokenizer 的细节不同。本地 `ILocalize.h` 只声明 AddFile/Find 等接口；对 external/references 的文件搜索没有取得 ILocalize 实现，不能凭接口或 KeyValues 宣称已证明原 CSOL 的具体实现。

保留跨行引号字符串是目录本身的要求。父任务选定的兼容合同不是跳过任意未知文本，也不声称与闭源原版 parser 字节级相同：

1. 继续以 token 流读取，保持引号内换行、转义、空白和后定义覆盖行为。
2. 只有期望键时，才跳过处于独立物理行的已证实装饰族：至少三个同种 `=` / `-`、`Ver.` 后纯十进制数字、精确 U+F142。quoted、inline、值位置均保留。
3. U+2003 仅在引号外作为空白；引号内保持原字节含义。
4. 只有 quoted key 与 quoted value 之间允许单个逗号。逗号作为键、重复、尾随、后接裸值/装饰行/半截引号都不能变成成功值。
5. 未知裸键仍须有值；缺值、坏结构、未闭合引号/块、非法 conditional 仍事务拒绝，保留调用者原词条表。不得截断目录、修改原资源或插入默认文案。
