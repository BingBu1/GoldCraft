# 近战重复选装、音效与左右手回归

用户在 v8 菜单实测中指出：已买刀变灰不能再选、买刀播放枪械拾取声、青龙右键挥动与命中声音反用，以及右手设置下刀仍在左手。本阶段优先修复这些行为，暂缓正在准备的 restart 性能计时。

## 重复选装与拾取声

旧 `WeaponService::CanDeliver` 与 `CSOL_DeliverMeleeWeapon` 都拒绝已有同种刀，因而服务器向菜单发送 Unavailable。曾拟在验证原实例后直接成功返回，以保持攻击状态，但这属于按反馈设计的幂等方案，尚无原版完整重复选装流程的 IDA 证据。

用户再次明确要求有原版 IDA 证据后才允许写入；上述方案与刀具拾取声抑制已全部撤回。原 HW 两条刀选装记录只证明选装编号与物品映射，不能替代重复选择的生命周期。买刀声音已定位至原 CS `CBasePlayerItem::DefaultTouch` 成功 Attach 后无条件播放 `items/gunpickup2.wav`，但原 CSOL 的选装交付和声音调用链仍须先核实。

撤回凭据位于 `build/csol-melee-regression-20261104/unproven-purchase-withdrawn/receipt.json`：三份生产源与公开 ReGameDLL patch 恢复原内容，候选未构建、未部署、未发布。测试候选也已独立保存并恢复。待原版链条闭合后再决定实现；不能先决定 no-op，再寻找支持它的证据。

## 原版音效依据

此次重新使用 IDA 核对原 MP 表，已发现原来按 WAV 文件名推断功能的错误：青龙右键命中槽是 `dragonsword_hit1.wav`，空挥槽是 `dragonsword_stab_hit.wav`。左键命中和空挥分别按斩击序号选择对应 hit/slash 资源，不能随机选择。原模型事件另引用的缺失 `dragonsword_stab.wav` 仍遵此前用户决定省略，不用命中声音填补。

详细原地址、表字段、实际二进制身份及验证由本阶段 `build/csol-melee-regression-20261104/sound` 保存。音效、持刀方向的完整源码修复与专项仍在进行；本记录不表示新修复已经构建、部署或通过实机听感。
