# 后续补丁自动停服与恢复启动

用户要求后续补丁自动停止服务器、完成后自动重启。当前累计包、Nightfall、Nightfall 热修复（含下载恢复）和 GuestBootstrap 的新包生成入口已统一接入；历史已交付 ZIP 未改写，本轮没有操作本地游戏或正式服务器。

更新器先核对完整包、签名和省略基线。预检失败不打断服务器，`-Plan` 不启停任何进程。需要写入时，以原 `.state` 角色记录、PID、创建时间及实际可执行文件路径确定受管实例，再调用标准 Stop.cmd 所用的原 `scripts/Stop-Servers.ps1`，通过既有控制台命令保存退出。服务端和监护进程都退出后才备份／替换文件；更新期间持有共享操作锁和原启动锁。

安装成功或完整回滚后，调用标准 Start.cmd 所用的原 `scripts/Start-Servers.ps1`，沿用服主原模式、端口与启动检查，并确认此前运行的角色已经建立新的进程身份。原本已停服则保持停止，重复安装已是当前版本时不重启。`-NoRestart` 可要求更新后保持停止；手动 `-Restore` 同样自动启停。实际重启仍会按原地图规则结束当前对局。

停服失败不会开始替换，不强杀服务端或猜测进程。写入失败但完整回滚后恢复旧服务，并保留失败退出码；回滚不完整时保持停止，保留原备份。启动失败明确报错，已验证的安装与备份保留，不伪报服务器已就绪。强行关闭更新器或机器断电后的恢复需重新检查事务和服务状态，不宣称进程已经消失时仍能自动执行重启。

## 源码组织

- `tools/server-update-lifecycle/Lifecycle.ps1`：进程身份检查、保存退出、等待监护进程、启动锁、恢复启动及错误边界。
- `tools/current-server-update/Update-Server.ps1`：完整预检后进入生命周期；明确标记能否安全启动，覆盖正常安装、恢复旧事务和回滚。
- `tools/server-update-lifecycle/package.py`：为新包携带公共实现；精确适配继承旧发行包的安装器，未知模板拒绝，幂等接入。热修复和六脚本包重新生成内部 SHA256SUMS，避免保留旧包校验清单。
- 四条既有打包路径、面向服主的说明与 AGENTS 后续约定已同步。公共脚本拆分维护，没有将服务控制全部塞进安装事务文件。

不会重新扫描全部载荷来轮询停服。进程退出使用有界等待，250ms 轮询；停止脚本最多150秒、监护退出最多15秒、启动脚本最多240秒，保留脚本自身更严格的超时。正常进度每10秒提示。原脚本输出使用固定的两组日志文件，避免长寿命子进程继承捕获管道导致更新器一直等待，也不生成无界编号日志。

## 验证及限制

`tests/server-update-lifecycle/run.py` 在全新 build 目录编译自有微型进程，使用真实 Windows 文件共享锁和原 Common／Stop-Servers 的控制台命令协议。它们只是受控夹具，不是 CS／Minecraft。最终 `build/server-update-lifecycle-20261116/test05/receipt.json`：25项通过，所有夹具进程已正常退出。

覆盖运行中双角色自动保存／停服／安装／重启、只读预检和损坏包不打断进程、配置字节保留、幂等不重启、手动恢复自动启停、`-NoRestart`、原本停止不误启动、停服错误不覆盖、写入失败完整回滚并恢复旧进程、回滚失败不启动部分载荷、启动失败保留有效安装与备份。实际 WinPS 调用累计34.375秒，只代表隔离测试过程，不作为正式服更新耗时或游戏性能证据。

`tests/server-update-lifecycle/package_checks.py`：6项通过，核对已发安装器转换、精确辅助脚本身份、校验清单包含全部新成员、重复转换字节不变、未知模板零修改拒绝以及原发行包保持。回执 `build/server-update-lifecycle-20261116/package-check01/receipt.json`。

首败均保留：test01／02 的测试捕获管道被长寿命子进程继承，已经通过普通文件重定向解决；test03 暴露 WinPS 5.1 快速进程的 ExitCode 空值，提前保留真实进程句柄后确认退出码，test04首次23项通过；补充回滚失败用例后最终test05为25项。全部旧夹具进程均已按其自有命令记录退出，没有杀游戏或忽略失败。最终Python包装器校验清单变动另做6项回归，没有重复运行未变化的进程用例。

本轮没有重制用户已下载的补丁，没有部署或重启主服／正式服；首次采用新入口的正式服更新仍需核验其实际启停与就绪状态。完整项目目标保持开放。
