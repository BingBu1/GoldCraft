# 灾变怪统一受击血效

血效由灾变怪物的公共 `TraceAttack` 触发，通过 `CsoMonFX` 通知客户端共用绘制器。枪械事件、近战实现和原生客户端枪击函数均无需增加血效调用。当前源码已完成，组件验证、完整构建、部署与实机结果分别记录，未获得的证据不计完成。

## 依据与实现

| 证据 | 发现 | 实现位置 |
| --- | --- | --- |
| CSOL client `f4145136…` 的 `02568CF0` 与原指令决策对照 | 场景怪按模型及命中组区分血、金属火花和无血；11类金属模型、护盾命中组8、无血模型有明确分支 | `native/csol/monster_impact.hpp` 保留原分类和弹种尺寸表 |
| SDK `CCSOLScenarioMonster::TraceAttack` 和 `AddMultiDamage` | 所有正常直击在怪物处汇合；累加器可能先结算另一个目标并触发换图或实体归池 | `native/csol/server/scenario_monster_pool.cpp` 快照效果后累加伤害，返回后核对规则、会话、回合、实体与租约 |
| 原SDK `RadiusDamage`、炮火与持续伤害调用 | `TraceAttack` 本身不能证明是普通枪击；火焰、爆炸也可能调用它 | 仅接受正有限伤害及 BULLET/SLASH/CLUB 与 GIB 修饰位，排除火焰、爆炸、持续伤害 |
| 现有 `CsoMonFX` 和 `MSG_PVS` | 旧消息为子型1/2/3加三个坐标；PVS为不可靠局部广播 | `scenario_messages.cpp` 改变长注册，旧载荷保持7字节，新血/火花为8字节 |
| 飞刀 `TraceAttack` 仅带攻击者，实际弹体在随后的伤害结算才提供 | 发射后切枪时，当前武器不能确定原始弹种 | 不读当前武器，不增加每枪映射；当前使用原client未知弹种默认尺寸4 |

新载荷为 `BYTE subtype, BYTE amount, COORD x, COORD y, COORD z`，血子型4、火花子型5。客户端严格校验长度与数量，不进入旧爆炸的高度偏移、音效或精灵分支。每次解析当前服务器的血精灵索引，避免换图复用旧索引。

普通 CS 玩家和人质不经过灾变怪物 override，原生血效保持。客户端没有另一条预测血效路径，因此同一服务端命中只绘制一次。单发霰弹每颗实际命中均保留，不用按帧去重误删命中。

## 适配边界

- 原版由客户端预测命中。本实现按用户要求使用怪物公共入口，由服务器确认并向可见范围广播，呈现有网络延迟。
- 原client弹种具有不同尺寸。当前 `TraceAttack` 无可靠弹种上下文，使用原表默认4；后续需要通用命中上下文才能恢复逐弹种尺寸，不能声称当前已经像素一致。
- CSO六参数血接口的专用调色板不在stock引擎中。本实现使用CS标准红色247及stock `R_BloodSprite`；粒子数量和颜色仍需原版画面对照。
- 仅覆盖直接物理命中。火焰、爆炸与持续伤害保留其独立效果，不补造普通弹痕血。
