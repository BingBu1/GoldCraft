# CSOL 双附属模型与弹量姿态

`v_alterationammogun` 的 `_parts01` 和 `_parts02` 现已同时载入、合并骨骼并独立播放。中文工具已更新；此检查点验证查看器行为，完整 CSO 游戏状态及同画面对照仍未完成。

## 使用

打开主体后，两个部件自动显示。在“CSOL 预览 → 组合模型”选择附属件，可分别播放、暂停和定位动作。主体切至 C 射击时，两部件也进入对应射击动作；勾选自动衔接后按客户端时长返回后续动作。

“预览当前弹量”“预览最大弹量”控制第一部件的固定待机帧；“C 射击后保持展开形态”控制第二部件的后续状态。这些是查看器输入，尚未恢复完整武器参数及状态判定，不表示从游戏读取弹量。附属 SPR 保留独立时钟。

从主体或任一附属件导出，都会收集全部三个模型及关联资源，按 common 原目录放置。打开部件时也可跳转完整武器。组合页支持滚动；旧单附属预览配置继续兼容。

## 实现依据

**F-01：两个部件有独立身份和动作。** E-01 中 getter `0x02515E60` 对普通版武器 577、EX 版 746 分别登记槽位 0/1 的 parts01/02。普通主体 78 骨骼，部件分别 37/35 骨骼，共享 `alterationammo_root`。实现逐槽位保存模型、骨骼映射、JSON、动作和时钟；绘制第二部件前恢复主体骨骼，防止串用第一部件的变换。E-03 包括分别隐藏部件的实际渲染负对照。

**F-02：第一部件待机是弹量姿态。** E-01 的槽位 0 更新 `0x02516240` 设置序列 0、播放速率 0，帧号为 `truncate((66.0f / 最大弹量) × 当前弹量)`。因此不能把它当普通循环动画。C 射击回调 `0x025163B0` 切序列 1，严格超过一秒后恢复固定帧；E-03 验证空弹、半弹、满弹及精确时间边界。

**F-03：第二部件采用独立状态转换。** E-01 的 `0x02515600` 使用展开 0.5 秒、收回 1 秒和 C 射击 1 秒，均严格超过截止时间。`0x02516360` 切序列 4；C 事件 `0x02515D72` 同时调用两个部件回调，再令主体播放序列 3。实现重现这些可证实的动作与时间；射击后是否继续展开使用显式预览选项，未猜测尚未恢复的游戏阈值。

P-01：主体打开 → E-01/F-01 的显式配套关系与动作表校验 → 分别读取部件 JSON、上传资源 → E-01/F-02/F-03 的双时钟和弹量姿态 → 按主体骨骼逐部件合并并绘制（E-03）→ 三入口依赖导出及离线重开（E-04）。
