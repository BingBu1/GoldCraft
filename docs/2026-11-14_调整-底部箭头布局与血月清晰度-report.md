# 按截图箭头移动F提示与体力条，增强血滴可读性

用户截图`fb9ef27d`将F提示指向屏幕底部中央、体力框指向其原右偏位置的底边，并指出永夜血滴难以看清。本轮只调整这些自定义展示，原CSOL人物技能、武器/弹药HUD保持原布局。

## 变化与依据

修改前契约位于私有`analysis/csol-action-hud-arrows-20261114/PREEDIT.md`。用户明确的箭头属于自定义位置授权，不冒称原版坐标，也不需要用另一原版面板的位置代替。

| Evidence | Finding | Path |
| --- | --- | --- |
| 用户箭头终点约为1280×720画面的(640,700)、(808,700) | F整体横向居中、底部保留安全边距；体力条沿原右锚点下移 | `action_hud_layout.hpp`、客户端`human_kick.cpp` |
| 实际旧64px帧的滴血半径1.3，在720p约31px图标内小于一像素 | 增大显示图标、血滴源直径和红色对比度，保留下落运动与固定月面 | `phase_snapshot.hpp`、`Prepare-ChallengeMoon.py` |
| 实际`hud_style::MakeLayout`、技能正常/抬高位置和330px购买提示 | 底部新增控件留出弹药区；窄屏/放大HUD时体力框在右侧上移，F仍底部居中 | 实际布局363项及三个VGUI owner检查 |

1280×720默认下：F键提示框y=686，高26，整体中心x=640；体力框保留x=813，底边y=712。体力框右端限制在原弹药文字之前，宽度按可用空间收缩。低分辨率或HUD放大时，体力框放在右侧卡片与购买提示上方，避免移到另一个原控件上。

阶段图标在720p由31px增到45px，月面血迹改为更亮的红色，血滴直径增大并带高光，增加下落距离。继续使用真实32帧、每帧50ms的循环GIF；游戏只消费同帧图集。源图沿用上轮通过指定imagegen CLI生成的透明月亮，动态帧由已有准备器生成；本轮没有发起额外生图API请求。

源GIF和图集以v2副本保存到本地`assets/generated/csol/blood-moon`，不进入Git；实际游戏资源路径维持既有`night_blood_v1.tga`，须按新SHA更新服务器资源清单并由客户端下载/缓存校验，不直接在运行中覆盖已发布清单的文件。
