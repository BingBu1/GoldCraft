# 龙炎碰撞后停滞与事件方向

本阶段修复两个有原版证据的错误：火焰碰撞后没有恢复发射速度，以及客户端事件把玩家纵向后坐力用作水平偏转。人物 HUD 和材质下载已在 `9d5edb4` 单独发布。本阶段不宣称所有存活目标穿透或火焰最终观感已完成。

## 原版依据与实现

原 MP SHA-256 `39f962f34816411e615f01e5279d914204f7fd07c5a5112b0b303acafe0308b2` 的 `106243F9` 每次 Think 将保存的发射速度写回实体速度；有风分支则叠加风。当前移植在 Shoot 保存速度，并在原有 0.02 秒 Think 中恢复，保留五路共享命中集合、0.75 秒寿命和 BSP 接触销毁。

原 MP 事件的第二整数参数来自构造初始化为零的武器字段；原 client `2579950` 将该参数加到 yaw。移植原先使用玩家 punch pitch，导致纵向后坐力变成水平事件偏转。服务端事件和客户端预测都改用原默认零值，保留第一个整数参数 7。客户端仍正常消费远端事件明确传来的 pitch/yaw 参数。

没有调整火焰扇形角度、尺寸、透明度或速度。这些基础参数的原版对照没有发现不一致，不能用随意增亮掩盖运动或渲染缺陷。

## 验证

- 完整客户端生产 TU 与原宿主随机函数：195 项通过；旧版本相同夹具 8 项失败。
- 完整服务端生产 TU、真实 SDK 对象及可控引擎入口：事件 80 项、生命周期 10 项通过，对应 SDK 边界 374 和 69 项通过。旧版本分别精准失败 20 和 3 项。
- 实际 ReHLDS `SV_Physics_Bounce`、`SV_PushEntity`、`SV_ClipVelocity`、Think/Impact 及递归 hull 函数：三个帧步长、12 条运动轨迹通过。夹具是固定干燥场景和真实六平面盒碰撞，不等于运行中的完整地图或 Studio hitbox 验收。
- 两份完整 DLL 各重编一个 TU，客户端 201 对象、服务端 346 对象核对通过；输入保持、无未知依赖，x86 PE/PDB 匹配。后续源码仅收窄一行注释，代码内容保持。

旧致死碰撞停在 x=128.96875，直到寿命结束；修复后重新前进，越过目标远端 x=176，并在 x=599.96875 的 BSP 边界销毁。存活的 solid3 目标仍阻挡火焰，同一轮多次接触只伤害一次。因此，这组证据支持“击杀后继续飞行”，不能升级成“全部存活目标可穿透”。原引擎 solid5/6 队列和其他弹体特判已排除为当前龙炎路径，没有据此修改公共碰撞规则。

本地证据目录：`build/csol-character-hud-regression-20261103/balrog-sdk-08`、`build/csol-balrog-physics-20261103-02`、`build/csol-balrog-original-fixes-20261103`。父级核对 SDK 结果 1016 个引用、物理结果 15 个引用以及完整构建 10 个引用。原 IDA 证据保留在本地研究目录，不发布二进制或反编译资料。
