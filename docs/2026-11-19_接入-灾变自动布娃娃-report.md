# 灾变自动布娃娃

MetaHookSv 的 BulletPhysics 已在本地沙盒 B 启用自动布娃娃。进入标准死亡动作、具备有效骨架和命中盒、使用单位缩放的 Studio 模型可参加客户端模拟。客户端控制台用 `bv_auto_ragdoll 1` 开启，默认值为 1，设 0 会回收自动生成的刚体。已有手工物理配置优先。

## 客户端接线

- `AutoRagdoll.cpp` 从 Studio 命中盒选取最多 12 个刚体，按相连骨架生成关节。人物和四足模型共用构造器。每个客户端最多同时模拟 16 具。模型配置首次遇到有效死亡时生成，随后在当前地图内复用。
- `BasePhysicManager.cpp` 使用收到的实体状态与死亡活动触发。玩家的物理对象可交给原生 `ClCorpse`，在复活、尸体槽重新分配、关闭设置和换图时释放。普通怪物仍按服务器发出的尸体生命周期回收。缺少可用骨架或死亡活动的模型沿用现有死亡处理。
- `exportfuncs.cpp` 通过实际 Studio 绘制回调采样死亡姿态，采样与绘制物理姿态时暂时绕开 Renderer 骨骼缓存。此功能属于自定义客户端表现，服务端的伤害、刷怪和死亡时序仍由原有灾变逻辑负责。[BulletPhysics 补丁](../patches/bulletphysics-goldcraft.patch)

## 构建和实测

固定上游 BulletPhysics `9113f3701dea464d451efb12b26a0876c0cd107e` 的补丁重放通过，涉及 19 个文件。x86 AVX2 构建通过，CTest 10/10，覆盖复活、尸体槽复用、换图清理、容量、异常回退和 Bullet 地面碰撞。150 个人物及 24 个怪物外观的骨架和标准死亡动作检查通过，包含僵尸犬。8 个 v21 模型经生产解码器检查骨架、命中盒和序列表。另有 5 个外观没有标准死亡活动，`null.mdl` 无有效刚体。
