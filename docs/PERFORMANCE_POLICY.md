# 全代码性能约束

用户于 2026-11-10 明确要求：所有新增和修改代码都以极致性能为持续目标。此要求适用于客户端、服务端、菜单、资源与下载、地图切换、工具，以及后续会话和子代理。

先用实际 CPU／调用栈、内存分配、I/O 或帧时间采样定位成本，再选择算法、数据结构、缓存、批处理和并行方式。准备冷资源时明确线程和生命周期；避免绘制、输入和逐实体路径中的重复解析、临时分配、同步磁盘／网络访问和无界缓存。

性能优化必须保持原版 IDA 已证行为、精确浮点、服务器权威、资源校验和线程安全。不得用省略效果、跳过验证、降低正确性或不安全并发换取速度。仍遵守 [先取证后实现](CSOL_IDA_POLICY.md)。

每个性能阶段分别记录源码成本、构建与功能检查、实际采样和实机结果。使用同条件对照；微基准、简单计时、测试断言数量或编译选项不能代替实际游戏性能证据。没有有效采样时，明确记录性能仍待验收。
