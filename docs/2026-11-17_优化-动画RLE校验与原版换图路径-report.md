## 校验算法修改

修改前封存 `analysis/animation-words-20261117/PREEDIT.json`，含旧源码 SHA、实际 profile 身份和原版消费者复核。此处是项目加载安全边界的宿主优化，不宣称原 CSOL 使用这套标签或标记算法。

每个字节的 header/sample 角色由两个 64 位掩码表示，另一个掩码记录已经完整验证的真实 run 起点。每 64 个输入字节按需使用 24 字节标记，原来对应 64 字节；实际 vector 容量仍取决于分配策略，尚未测峰值内存。范围检查、valid/total 约束、头/样本冲突、四字节终点 padding、实际帧遍历、隔离轨道分类及加载代次规则保留。临时标记仅存在一次函数调用内，没有全局缓存、异步引擎访问或跨图复用。

F02（validated，n/a_re，高置信度，E04–E05）：可把逐字节角色冲突检查合并到机器字操作；同一调用中，已完整验证且字节不变的同一起点可复用角色标记。首次实验只看 header 角色，错误把第二个 header 字节当作起点，已由明确边界检出；该版本未部署。修正版单独记录 `starts`，仍逐次读取和检查 run 的范围与帧条件。

P02（callflow，E04–E05）：实际 loader/资源读取 → 完整安全标签/RLE 校验 → 机器字角色冲突检查 → 仅登记真正的已验证起点 → 发布原有安全 view → 原有 sampler 与生命周期。失败仍返回 Invalid，不强制成功。
