# 大灾变晚加入自动复活接线

当前正式服仍是旧版，战斗中后加入的人不能凭此次源码修改自动复活。本批已实现穷途末路的免费自动复活接线，完整客户端和服务端构建通过，本地真实专服的两个自建假客户端已通过37项生命周期检查。正式服部署、真人联网与客户端HUD画面仍待；消耗品 5/6/R、数据库持久化和团灭续关仍有独立未完成接线。

## 行为

成功选好人物时记录晚加入的起始时间，保留到 `GetIntoGame` 进入观察模式。普通死亡则在原 `PlayerDeathThink` 从 `DEAD_DYING` 转为 `DEAD_DEAD` 时起表。两者共用原等级和难度延时：`min(60, ((基础总等级-1)/10+3)*5) × 难度列6`。例如等级1、倍率1时等待15秒；不是所有地图或难度固定15秒。

`PreThink` 在观察模式的提前返回之前处理到期，读取真实升级进度、当前难度、队伍及回合状态。仍有存活CT、游戏已经开始且回合没有结束才允许自动生成。最后一名队友刚在本帧死亡时，会在生成前重新统计人数，防止旧缓存错误放行。`mp_forcerespawn` 的原生快速复活不再绕过灾变计时，普通CS/ZP保持原路径。

生成使用真实 `RoundRespawn`，恢复装备、角色、升级血量和观察状态；不重新安装地图TRG或波次。许可只在一个玩家、当前地图、回合和时钟生命的同步调用内有效，不扩大普通 `CanRespawn`。进入 `Spawn` 后立即撤销旧时钟，随后停止旧观察帧。断线、槽位复用、换图、换回合和回调取消均不能把旧许可交给后来玩家。

免费自动复活与Steam库存扣除相互独立。它不要求连接PostgreSQL，也不会在数据库不可用时免费发放复活道具。
