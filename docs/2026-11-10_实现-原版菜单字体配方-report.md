# 原版菜单字体配方

当前原版字体加载器固定用1024×768建立无 yres 的字体配方；此前宿主规则随分辨率变化，还额外应用语言最小字号，两者会产生不同字号。新增 `native/csol/client/menu_font.hpp` 的 `GetCSOScaled`，沿用不可变 HFont 缓存，并独立返回实际 Surface 字体高度。旧 `GetHostScaled` 明确保留为宿主适配。

## 实现和检查

`GetCSOScaled` 对9/12/8/11分别提交14/19/12/17，非比例配方不缩放，上限128。缓存按family/tall/weight/flags匹配，不重新配置已有字形的HFont；失败保持handle0；Invalidate后可建立新handle，实际度量随Surface查询。

`tests/csol-menu-font` 使用实际生产header和匹配SDK，覆盖多分辨率、多语言与旧宿主规则对照、配方/度量差异、资源替换、失败及重建；对旧重复配置行为保留反例。测试计数器位于`tests/csol-hud-style/allocation_probe.hpp`，只统计C++ new/new[]，不宣称覆盖全部CRT/驱动分配。

最终收据 `build/csol-menu-font-cso-20261110-03/receipt.json`：x86 C++20/O3/ThinLTO/AVX2/precise编译运行通过，157项、25输入不变。预热1000次：C++分配0、重复字形注册0、屏幕读取0，实际高度读取1000。没有GDI像素、实机菜单或FPS验收。

本提交仅发布独立helper及测试基础；购买/选人消费者、原生详情控件、双端构建和实际画面归菜单联合阶段，不以此关闭菜单或完整灾变goal。参见 `docs/2026-11-10_重构-CSOL购买与选人菜单-report.md`。
