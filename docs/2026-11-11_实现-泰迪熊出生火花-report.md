## 宿主适配和成本

固定池上限为 128 emitter / 1200 particle，保留首空分配和失败顺序；这是本消费者的宿主配额，不宣称已复刻原版跨效果共用池竞争。高水位使无效果帧 O(1)，reset 只退休旧槽，不清空整个数组。空帧仍推进时钟，防止下次出生把整个空闲间隔用于积分；实际回归覆盖 100→200 空闲、200 收包、200.016 更新。

模型只在首次接受相应消息时通过原引擎加载，并按会话缓存；绘制与逐帧更新不查路径、不进行文件读取、堆分配或同步 GL 查询。Additive 按 sprite/frame 合批；绘制保留 PVS、RGB、alpha、UV 和精确几何。两种 sprite 最多 514 个批次桶，粒子链表有固定上限。尚无实机 CPU/分配/I/O/帧时采样，不宣称 FPS 或首次加载耗时已改善。

链式接收保留其他 TempEmit 消费者。epoch 和重入 guard 在引擎回调后重新检查会话，Begin/End 成对恢复状态；lagged message 不清空已存在的粒子，不倒退已积分时间。模型帧数 1..256 是宿主安全边界，不冒充原版资源上限。
