# 大灾变爆尸与音效

2026-11-21 按用户指定的玩法增加爆尸。玩家击杀普通僵尸或非 BOSS 精英时，每次致死结算按 2% 判定。近战武器的实际头部命中致死时改用 50%。同一伤害批次记录命中者、受害者和怪物槽租约。普通射击爆头、枪托和踢击使用普通击杀概率。

触发时服务器发送一条 GoldSrc 碎片消息，生成 4～5 块碎片。受害者立即隐藏，原死亡计时器归还怪物槽。音效在服务器预缓存后从死亡位置播放一次。新玩法的开关和两档概率沿用单份 `gameplay.json`、即时 CVAR 和 M 管理员菜单。缺少音效或碎片模型时使用常规死亡流程。冻结碎裂仍由原冻结死亡处理。

## 资源与验证

用户提供的 `KillZombie.ogg` 转为 22,050 Hz、单声道、16 位 PCM WAV，时长 2.011 秒。安装资源为 `cstrike/sound/goldcraft/killzombie.wav`，工作区资源原件在 `sandbox/private/scenario-assets/sound/goldcraft/killzombie.wav`。SHA-256 为 `9c1a0f35cec52ebd4594bed2becfbcb3a87f2ecf0e37a88fd7426b8951a6de43`。

统一配置 1,006 项通过，覆盖两种旧配置的默认值、开关和概率端点。AMXX 1.9.0.5303 编译通过。死亡 SDK 测试通过 1,523 项，包含隐藏尸体的六项定时归还回归。死亡和声音夹具在初始化怪物池前安装引擎模型指针接口。夹具使用真实特效注册表的清理步骤，死亡音效断言逐一核对各样本只缓存一次。

旧版隔离专服对照通过 20 项。真实小刀击中胸部、头部及普通玩家伤害均能致死，尸体仍进入快照。测试插件预缓存音效后，实际 HTTP 返回同一 SHA-256。夹具退出码为 0，隔离文件及所核对的 Steam 与共享服文件已复核。见 build/scenario-zombie-gibs-20261121/live-baseline/receipt.json。
