# 近战菜单、BOSS 血条与地图重载整合

本阶段基于已经部署的技能崩溃修复重新构建，避免直接安装较早的菜单候选 DLL 而回退 HUD、崩溃记录器和技能资源修复。

## 改动范围

- 购买目录加入青龙偃月刀、旋风 SKULL-9，使用 v8 资源路径。两刀免费是用户指定价格，不声称这是原版 CSOL 售价。
- `CCSOLScenarioSession::Precache` 显式登记 `boss_health::Resources` 的五张主图与三张能力图。过去第五张及三张能力图已由其他清单覆盖，但前四张缺失，使已部署的客户端血条绘制提前退出。复用集合去重和现有缺失/空文件拒绝流程。
- 人物、HUD 和购买资源只检查存在时，改用引擎 VFS 的 `GET_FILE_SIZE`，避免每次 `restart` 为存在检查读取整份模型正文。JSON/清单解析、模型加载和每图下载登记保持；性能提升须以真实重载计时为准。
- 保留已部署菜单的武器 ID 分类及玩家生命代次检查，以及模型表 NULL 结束项与五个技能世界 SPR 的模型预缓存修复。
