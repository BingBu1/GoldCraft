# 文件打开元数据与原版声音缓存

实际专服采样显示，文件按路径查询元数据是换图热点。本轮让已经选定并打开的常规文件直接提供自身大小和时间，避免额外按名称打开；仍按原 VFS 顺序选择文件，PAK 和失败回退保持原路径。源码、固定上游补丁回放和旧 DLL 语义基线通过，新完整构建和新 DLL 实际回归通过，尚未部署。完整换图验收仍开放。

同时补查原 CSOL 声音加载。原版有声音名称表、有效缓存快路和 `fs_lazy_precache` 分支，不能用资源总数量推断每图完整解码，也不能断言原版默认把全部声音延迟到首次播放。

## 源码与测量

`OpenFileMetadata` 无全局状态、不分配内存、不打开路径，只在 `_fstat` 成功且为常规文件时提交输出。失败不改变输出。元数据来自实际打开的文件，避免路径在查询期间被替换后将另一文件的大小写入当前句柄。原有 SHA、CRC、RLE 与最终 VFS 复核继续执行。

修改前记录 `analysis/fs-open-metadata-20261117/PREEDIT.json`，包含源码/补丁 SHA、实际采样摘要和离线成本。五轮交替调用当前 CRT，覆盖人物、武器、声音、地图、SPR 和界面等实际文件；不是原版 CSOL 的性能测试。

## 原 CSOL 声音的新增证据

样本：x86 `hw.dll`，ImageBase `0x37100000`，SHA-256 `c7bddfda93c2e0877ea126a15a318b83cce74c59bb95e38a7301b08033ac7783`。所有地址为 VA。先用规范 `open.ps1` 复用已有工作区 IDB，真实会话 `cso-resource-existing-20261117`；部分 Hex-Rays 输出有栈平衡警告或失败，结论采用保存并与 PE 匹配的指令。

| 原版位置 | 可确认的行为及边界 |
| --- | --- |
| 引擎表 `383099F8` → `378C7CF0` | 服务器声音注册入口；检查名称，查重并保存索引，尾调用 `37A6B880` 维护名称/索引关系。不能据函数名称推断解码所有声音。 |
| `378F66E0` | 客户端按名称找 136 字节 sfx 记录，缓存 owner 在 `+128`、代次字段在 `+132`；同名路径保留实际 owner，复用过期槽时可能先释放缓存。不能因此说所有声音永远跨图保留。 |
| `378F7120` → `378F66E0` / `378F8ED0` | 声音预缓存路径受声音系统状态、名称和 `fs_lazy_precache` 控制。普通声音在该 CVAR 为零时调用加载器；`*`/`!` 前缀另走名称登记分支。 |
| `382FF1E0` / 值 `382FF1EC` | 原结构中的名称确为 `fs_lazy_precache`，静态初始字符串为 `0`。没有采集原游戏实际运行值，不能当作原版已开启延迟的证据。 |
| `378F8ED0` 的 `378F8F2D`–`378F8F65` | 调 `Cache_Check`；缓存存在且输出格式条件满足时跳到返回，不重新走文件读取/解码。特定格式条件下释放后重载；缓存丢失同样继续加载。`*`、`?` 前缀有独立路径。 |
| `37840DB0` | 客户端模型按索引访问时检查实际记录的加载状态，必要时调用模型加载器；它与同名缓存和登记阶段是不同消费者。模型与 SPR 其余新读取仍在分析，不作为本轮修改依据。 |

F02（validated，n/a_re，高置信度，E05）：原版已具备名称登记与实际声音加载分离、有效缓存复用和条件延迟分支。声音资源数量不能直接等同每图的解码量；同时普通声音也可能在预缓存阶段直接加载。尚未证明原版当前配置的实际值、全部换图清理路径、特殊音频后端以及 NAR/PAK 当前解析成本。

P02（callflow，E05）：客户端声音预缓存 → 系统/名称条件 → 名称查找 → CVAR 选择是否提前加载 → 有效 cache 或文件读取/解码 → 播放消费者。此链说明不同阶段的成本，未修改当前声音策略，避免未经验证地把等待移到首次开枪或技能。

## 时序与剩余验收

先核实际双端采样和原声音消费者；再对 5,130 个当前资源测量 CRT 元数据；封存 PREEDIT 后修改 stdio 路径，执行旧实际 VFS 基线和固定上游回放，随后在共享单任务构建窗口完成新文件系统候选。构建状态、自动化、部署和游戏证据分别记录。

后续需要实际新 DLL 的同夹具、窗口/进度与完整跨图 CPU/IO、普通服务器、公网和多人；继续追归档、模型/SPR/纹理的准备与清理。本轮组件结果不能关闭这些项。完整大灾变、普通黑龙炮和全部自定义要求保持开放。
