## 现有证据

- Windows 应用事件：`MetaHook.exe` 在 `hw.dll+0x1BB099` 发生 `C0000005`，共 4 次：11/1 19:28、19:50（**用户正式安装 `E:\Steam\…\Half-Life`**）、11/2 16:17、11/3 21:34（沙盒 B）。另有 11/1 17:11 的 `+1BB006` 属于已知的退出阶段故障（音乐 ExitGame），与此无关。
- 沙盒 `hw.dll`（`9ba9a2db…`）`101BB070` 是引擎的不区分大小写字符串比较（上限 99999 字符；只读 PE + capstone）。`101BB099` 为 `movsx edi, byte ptr [esi]`，即**读取第二个参数的首字节**时访问违规：有一个非空但无效（悬空或垃圾）的字符串指针被传入引擎。
