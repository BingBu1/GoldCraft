# 换图清单确认与重连进度

同一客户端构建在本地专服的两个换图方向上，开启清单确认调整后，清单接收由约 9.7–9.9 秒缩短到 5.1–5.3 秒。仍需 27.8–30.0 秒才能看到新地图，后段仍出现窗口未响应。候选结束后恢复了沙盒文件。

## 双向对照

同一台本地 ReHLDS 专服、同一份 GoldCraft 及匹配 PDB、同一份 CSOLSupport 和 Renderer。在两个客户端进程中分别加载缺少和包含 ACK 重排符号的目录。资源验证计数与挂载检查通过，四次换图均无需 HTTP。两轮先后执行，主机负载未固定。

| 路线 | 清单接收用时（关 → 开） | 首个新视图（关 → 开） | 后续 HUD 回调（关 → 开） | 未响应采样点（关 → 开） |
| --- | --- | --- | --- | --- |
| 穷途末路 → 失落之城 | 9.734 → 5.114 秒 | 31.557 → 29.985 秒 | 32.042 → 30.504 秒 | 6 → 13 |
| 失落之城 → 穷途末路 | 9.897 → 5.277 秒 | 31.270 → 27.847 秒 | 31.579 → 28.157 秒 | 5 → 9 |

清单用时从首次观测到部分条目算到完整清单交给校验。开启侧两次分别记录 160 和 166 次重排发送，关闭侧未走重排分支。四次校验各自核对 3,461 或 3,518 项资源。未响应列是采样点计数，画面验收仍需实际观察。

失落之城一程的专服开图用时为 11.334 和 13.713 秒，GameUI 首次出现有效连接进度窗的记录为 11.456 和 13.832 秒。之后，GameUI 进度类型随已接收清单切到 GoldCraftResources，进入原生预缓存后恢复 Connecting。两轮清单接收期间，专服主线程分别增加约 0.094 和 0.016 CPU 秒。

P01（E01、E03）。远程换图的主路径是专服准备地图和资源 → 激活时发重连 → 客户端原生 Connecting → 清单接收、资源校验和原生恢复。单机主机具有开图前的局部 GameUI 入口。若需让远程玩家在专服准备时就看到进度，需另行验证通知时序及连接生命周期。

P02（E02、E03）。状态 3 且接收 v4 → 暂存当前代次已有的空发送 → 读包 → 同代次、同状态才发送 → 原有预测检查。普通连接、上传、demo、listen server 或缺少符号时沿用原路径。HTTP 继续使用独立 Asio 协程队列和原有校验。

## 构建、测试和恢复

- 封存的 x86 产物为 GoldCraft.dll 29c5406a9eb172789d79449c4b782e95b369b239292bc87b37af1d9dde0dda6f 和对应 PDB。受影响的 6 项源码逐一核对构建收据。该收据覆盖 1,454 项编译输入及 40 项链接输入。
- 用封存的可执行文件复跑 40 个资源桥接场景，含 3 项清单进度及取消测试。预缓存测试 552 项通过，其中 15 项覆盖原发送、重排、取消、回退和非 v4 状态。
- 沙盒 B 预检了专服 325 项 HUD 资源，实载同一候选对照。前次关闭侧结束后，ACK 开启侧因服务端仍有玩家在启动前中止。本轮核对空服、起图和进程身份后补跑开启侧。结束后恢复 4 个客户端文件和运行登记，6 项受保护安装检查一致，崩溃记录无变化。
- 正式服及发布包尚未应用此候选。后续对照既有服务端 VFS 查询和模型校验优化，再测同路线的准备段与客户端恢复。原生进度窗实际画面、下载中取消与跨图、公网和多人继续验收。
