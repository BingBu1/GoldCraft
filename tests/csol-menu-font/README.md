# Menu font recipe regression

Compiles the production header against the pinned host VGUI SDK, using controlled surface/scheme implementations at its interface boundary.

Run tests/csol-menu-font/run.py from Git Bash with --compiler <clang-cl.exe>, --environment <x86-environment.json>, and --output <fresh-workspace-build-directory>. Outputs are compile/test logs and a receipt with the exact command and before/after hashes.

Checks the independently evidenced current CSO fixed recipes (9/12/8/11 to 14/19/12/17), maximum128 and no language minimum, separately from the preserved host adaptive policy. Also checks immutable handles, measured/configured height separation, resource invalidation, failures, SYMBOL flags, warm allocations/registrations/screen reads, and an old same-HFont resize counterexample. Controlled SDK metrics do not prove GDI pixels, old CSO vgui2 scaling, actual menu appearance or live FPS. See docs/2026-11-10_实现-原版菜单字体配方-report.md for module identities and the evidence boundary.
