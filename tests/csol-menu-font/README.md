# Menu font recipe regression

Compiles the production header against the pinned host VGUI SDK, using controlled surface/scheme implementations at its interface boundary.

Run tests/csol-menu-font/run.py from Git Bash with --compiler <clang-cl.exe>, --environment <x86-environment.json>, and --output <fresh-workspace-build-directory>. Outputs are compile/test logs and a receipt with the exact command and before/after hashes.

Checks the independently evidenced current CSO fixed recipes (9/12/8/11 to 14/19/12/17), maximum128 and no language minimum, separately from the preserved host adaptive policy. Also checks immutable handles, measured/configured height separation, failures, SYMBOL flags, warm allocations/registrations/screen reads, and an old same-HFont resize counterexample. Thirty-two refresh rounds cover unchanged families, committed family changes and rollback to the original family; reopening through the production cache must retain body/title/tab/Marlett handles with zero additional CreateFont/AddGlyphSet calls and use fresh metrics. Failed-recipe invalidation must permit the exact failed recipe to retry after repair while retaining successful handles. Explicit shutdown invalidation separately discards recipes. The controlled boundary models provider completion; it does not run the complete menu or the VGUI transaction. Controlled SDK metrics do not prove GDI pixels, old CSO vgui2 scaling, actual menu appearance or live FPS. See docs/2026-11-10_实现-原版菜单字体配方-report.md for module identities and the evidence boundary.
