# G43 canonical owner with shared CSOL stamina

Composes the production G43 owner view with the real canonical input runtime, the player-owned task runtime and three actual stock/CSO models. The controlled external stamina ledger represents the already-authoritative CSOL service; the fixture never seeds or advances a second CoF stamina cycle.

```bash
python -B tests/cryoffear-p345-owner/run.py --weapon g43 --sample <copied-original-MP> --proof <PREEDIT-owner.json> --compiler <clang-cl.exe> --environment <compiler-environment.json> --output build/<fresh-directory>
```

The runner verifies original sample/regions and immutable proof archives, then seals actual compiler dependencies before/after. Cases cover canonical input edges, per-player isolation, optional unavailable stamina, recoverable cold preparation, all action/stance labels, pending player tasks across model changes, life retirement, and hot reads without allocations or model lookups. Engine, transport and shared-ledger callbacks are controlled boundaries; no production map registration, whole-gun, deployment or gameplay/performance acceptance is implied.
