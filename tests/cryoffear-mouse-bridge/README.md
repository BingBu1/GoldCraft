# Actual CoF native mouse stage

Compiles the production x86 detour, actual FOV message/presentation code and
original arithmetic helper against the real SDK. Executes the detour with
relocated reference operands and an executable native continuation, including
packet-to-FOV-to-mouse delivery and explicit return to ordinary input.

The controlled installer and connection provider exercise absent/malformed
symbols, view/resource/connection/thread ownership, replacement during a
callback, shutdown while executing, and synchronous retirement during hook
installation. Sentinel SIMD values test callback clobber protection. This
fixture controls rendering/session services; the separate FOV fixture covers
real session resets, and the original arithmetic fixture supplies the
independent instruction oracle.

Run the command in the [integration report](../../docs/2026-11-12_实现-CoF原鼠标缩放与宿主接线-report.md).
Physical devices, real engine/MetaHook delivery, game visuals and live CPU/frame
sampling remain separate acceptance gates.
