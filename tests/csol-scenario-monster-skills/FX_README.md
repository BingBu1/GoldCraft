# 怪物特效与消息验证

`client.cpp` 链接实际 `scenario_effects.cpp`，通过消息注册入口测试 `CsoMonFX`，捕获引擎 SPR、声音和绘制调用。`messages.cpp` 链接实际 `scenario_messages.cpp` 与匹配 ReGameDLL 头，捕获注册、消息目标及字段。测试边界只有引擎 API；没有复制生产方向算法或提取替代函数体。

覆盖爆炸精灵索引、30 FPS、scale2.5/flags0、坐标符号与Z偏移、声音位置，错误类型/长度、缺资源/API，以及陷阱四方向的近远判定、原四帧位置、320/640资源、衰减、Health/HideWeapon、地图与HUD重置。消息覆盖PVS/单玩家、7字节合同、原ScreenShake三个SHORT、重入保护和失败前不发半包。

编译必须绑定父任务指定的最终独立候选。`fx-prepare.py` 仅复制两份生产TU、测试、保守头文件闭包，并记录安装工具链/SDK输入；它不启动编译。`fx-run.py` 按落盘命令逐个编译、链接、执行，检查实际include均已预先记录且输入未漂移。两步均只能输出到工作区 `build`。准备完需等待主任务分配单job窗口。

证据边界：这些检查不证明OpenGL画面、HTTP下载、专服碰触或多人效果。正常血量的amber颜色是当前宿主适配；原CSOL的可配置HUD默认颜色尚未核实。技能启动和旧版未实现负对照属于父任务的真实服务/实体组，此组不把缺接口的旧版链接失败当作行为负对照。
