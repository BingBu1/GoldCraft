# G43 complete ordinary primary

Execute the complete matched original `10044690` plus the real autoaim and
eye-position instructions, then compare typed C++ state and ordered ABI
callbacks. The proof must precede implementation and bind the original module,
instruction bytes, archived IDA evidence and exact constants.

```bash
python -B tests/cryoffear-g43-shot/run.py \
  --sample "$COF_MP_SAMPLE" --proof "$COF_G43_SHOT_PREEDIT" \
  --compiler "$COF_CLANG_CL" --environment "$COF_COMPILER_ENV" \
  --output build/cof-g43-shot-new
```

Use a fresh workspace output directory. Original binaries and disassembly are
private inputs. The runner hashes actual compiler dependencies and evidence
before/after, and rejects empty/truncated/incorrect/extra answers. A deliberately
stale recoil-angle provider must differ from the original.

Cases include primary and pressed-button gates, secondary-clock independence,
underwater/empty behavior, last-round and random loaded animations, cooperative
effects/audio parameters, damage conversion, large skill-expanded magazines,
infinite ammo, exact float clocks and post-recoil angles. Host-only checks stop
at each rejected/retired callback; 10,000 hot calls allocate nothing in the
fixture. These checks do not establish actual game CPU/frame-time performance.

The caller prepares the original spread increment and current spread vector;
no authored/default scalar substitutes for the original spread lifecycle.
Engine/damage/audio consumers are explicit ABI boundaries. This is a primary
component, not an admitted SDK weapon or gameplay/multiplayer acceptance.
