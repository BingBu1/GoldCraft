# Original CoF crosshair and network quantization

Compiles the production geometry and codec/quantizer, then executes the private
SHA-pinned client draw instructions and original engine DT_FLOAT conversion.
It compares all three rectangles, RGBA calls and the reachable0..10 network
integers, retaining integer and float operation order. No original bytes,
binaries or assets are published.

The original draw stage covers the magazine-pistol branch and its aim,
telescope and option gates. Outer HUD/weapon/lifecycle gates use the separate
actual SDK bridge fixture. The engine replay proves reachable quantization;
it does not claim general delta encoding or actual network gameplay.

Commands and module identities are in the
[report](../../docs/2026-11-12_实现-CoF准星快照与原版三线绘制-report.md).
