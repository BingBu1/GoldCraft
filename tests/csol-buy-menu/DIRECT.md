Purchase regressions cover the evidenced ordinary mode15 registered-default path: command dispatch followed by local Close in the same call, independently of later server authority results. They replace the withdrawn wait-for-reply and success-causes-close expectations. The original evidence is client OnCommand `0x18130B754` dispatch then `0x18130B75D` Close, with the separately verified default-state chain; the tests execute the host adaptation and do not independently prove that original evidence or restore runtime basket overrides.

Ordinary-purchase cases include delayed, duplicate, unrequested and mismatched token/item replies; rapid reopen and multiple outstanding purchases; current UI balance/status/catalog preservation; session reset; and 16-bit token wrap/reuse. The host uses bounded fixed token-to-item bookkeeping. After an entire token cycle, an old reply with both the same token and same item is indistinguishable from a new reply in the existing wire protocol; tests cover token retirement and mismatched-item reuse without claiming an unavailable wire generation field.

The old successful-ID rebuy queue and its per-item catalog/result tests are withdrawn. The registered F2 `rebuy` command sends `cl_rebuy` without client history or a catalog. The human explicitly removed the original 0.1-second wrapper interval on 2026-11-10; tests require every repeated same-time F2 command and same-time buy opening/reopening to dispatch immediately. This is an intentional deviation from the original shared timer. The timer-only autobuy/drop hooks are removed, leaving their native command owners. Tests distinguish visible-menu `rebuy_in`, which dispatches then closes in the same call. They avoid local death/spectator authority gates and keep detached ordinary acknowledgements independent. They exercise command callbacks, not a physical F2 binding or the server snapshot replay.

The receipt records the complete dependency closure, matched controls library, resources, compiler identity and before/after input hashes. Compilation and controlled native execution do not establish live GPU behavior, gameplay, IME or actual FPS. The token table's fixed 128 KiB storage is a protocol bound, not a measured performance result.
