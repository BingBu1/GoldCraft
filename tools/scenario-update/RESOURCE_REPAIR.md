# 冰桑：灾变服务器资源修复

适用于已安装 **20261024-CSOL + 20261101 灾变更新** 的服务器。累计修正版包含前版 111 项资源，以及后续发现的 BGM 等启动必需资源；具体数量与完整哈希见包内清单。装过前版资源补丁也可直接运行，相同文件自动跳过。保留稳定 DLL、纯 CS 模式 2 入口、密码、端口、管理员和 Minecraft。

1. 用原 `Stop.cmd` 正常停服。
2. 将 ZIP 解压到服务器安装目录之外的新文件夹。
3. 运行 `Update-Server.cmd`，输入包含原 `Start.cmd` 的服务器根目录。
4. 成功后运行原 `Start.cmd`，让玩家退出后重新连接。

脚本先检查包内哈希、清单列出的既有资源，以及稳定引擎/游戏 DLL/启动分支。缺失或不同会明确停止，避免继续部署不配套的文件。已存在且 SHA-256 相同的文件跳过；同名但不同版本的角色和手模会正确替换。大资源只读取校验，不重复备份或复制。

文件安装到服务端 `cs/cstrike` 下；既有 HTTP 从这个相同资源目录提供客户端下载，仍共用原端口。此包不更新启动器的 DLL 发布目录，也不含正在开发的新购买/技能 DLL。已有客户端缓存不会被本脚本删除；实际入服、B 菜单、选人升级、默认 K3 和资源下载需要更新后确认。

失败自动回滚。需要撤回本次资源修复时，先停服，再运行 `Restore-Server.cmd`。独立 `.bingsang-resource-updates` 备份不会覆盖之前灾变模式更新的回滚记录。仅查看计划可运行 `Update-Server.cmd -Plan`。

前版资源审计遗漏了 MP3，导致正式服继续报 `scenario BGM is missing or empty`。本版补入必需音乐，仍须区分资源检查、安装器验证与远端真实入服；打包成功本身不代表游戏流程已经通过。
